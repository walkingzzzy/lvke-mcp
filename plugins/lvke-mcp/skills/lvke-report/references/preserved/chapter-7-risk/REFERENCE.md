# 第 7 章 · 风险分析与对策 起草

第 7 章决定项目"能不能扛住意外"。**不能写"无风险" / "风险可控"作为结论**，必须对每一类风险给出识别 → 评级 → 对策 → 应急安排的完整闭环。

## 必含 7 类风险

### 7.1 政策风险

要素：
- 国家 / 地方产业政策变化
- 财政 / 税收政策变化
- 环保 / 安全 / 用地政策变化
- 金融 / 利率 / 汇率政策

典型识别：
- 高耗能 / 高排放项目：双碳约束加强
- 房地产 / 城投相关项目：行业去杠杆
- 农业项目：耕地占补平衡变严

对策：
- 提前对接政策制定 / 解读单位
- 设置政策预案
- 选择政策红利明确的细分领域

### 7.2 市场风险

要素：
- 需求不及预期（量风险）
- 价格下跌（价风险）
- 竞争加剧（份额风险）
- 上游供应风险

典型识别：
- 周期性行业：需求高低波动幅度 ±30%
- 标准化产品：价格透明度高 → 价格战风险
- 关键原材料对外依存度高：供应中断

对策：
- 多元化客户 / 多元化产品
- 长协 / 锁价
- 上下游一体化

### 7.3 技术风险

要素：
- 工艺成熟度不足
- 关键设备故障 / 进口受限
- 知识产权风险
- 技术更迭被淘汰

典型识别：
- 新兴产业：技术路线尚未收敛
- 关键设备进口：地缘政治
- 数字 / AI 类项目：算法快速迭代

对策：
- 选成熟工艺为主、试点新工艺
- 关键设备国产替代评估
- 持续研发投入

### 7.4 财务风险

要素：
- 融资不到位
- 利率上行
- 汇率波动（进口设备 / 出口收入）
- 流动性风险
- 资本金不能按期足额到位

对策：
- 锁定贷款利率（固定利率 / 利率掉期）
- 外币远期 / 期权对冲
- 维持充足备用授信
- 优化资本结构

### 7.5 实施风险

要素：
- 工期延误
- 工程质量
- 安全事故
- 征地拆迁纠纷
- 用地 / 用海 / 用林审批延误

对策：
- 关键路径管理
- 工程监理 / 第三方质量评估
- HSE 管理体系
- 用地手续前置

### 7.6 环境与社会风险

要素：
- 环评不通过
- 周边居民邻避
- 用水 / 用能矛盾
- 文物 / 生态敏感目标

对策：
- 环评前置（甚至 EIA + SIA 双评估）
- 公众参与 / 信息公开
- 选址避让敏感目标

### 7.7 不可抗力 / 黑天鹅

要素：
- 自然灾害（地震 / 洪水 / 极端气候）
- 公共卫生事件
- 战争 / 地缘冲突

对策：
- 工程保险 / 财产险 / 责任险
- 应急预案
- 备用厂址 / 多元供应

## 风险评级 标准矩阵

| 概率 \ 影响 | 低 (轻微影响) | 中 (中度影响) | 高 (重大影响) |
|---|---|---|---|
| 高（>50%） | 中风险 | 高风险 | **极高风险** |
| 中（10-50%） | 低风险 | 中风险 | 高风险 |
| 低（<10%） | 低风险 | 低风险 | 中风险 |

要求：
- 每个风险给出 **概率 × 影响 = 等级**
- 高 / 极高风险必须配套对策
- 极高风险 ≥ 3 项 → 项目可能不可行

## 输出模板（每一类风险都按这个写）

```markdown
### 7.X.Y XXX 风险

**风险描述**：[发生场景 + 触发条件]

**风险评级**：
- 发生概率：[高/中/低 + 论证]
- 影响程度：[高/中/低 + 论证]
- 综合等级：[低/中/高/极高]

**应对措施**：
1. [预防]
2. [缓解]
3. [应急]

**残余风险**：[采取措施后剩余风险等级]
```

## 常见缺陷

1. **写"无风险" / "风险可控"作为结论** —— 评审专家最讨厌
2. **风险描述空泛** —— "市场风险：销量下降" → 没说降多少 / 触发条件
3. **没有评级矩阵** —— 高 / 中 / 低标签随意打
4. **对策口号化** —— "加强管理" / "密切关注"无具体动作
5. **缺残余风险** —— 写了对策但没说采取对策后剩多少风险
6. **黑天鹅一概省略** —— 不写不可抗力 / 自然灾害

## 关键避免

- 不要让"风险评级"全是"低"或"中" —— 任何项目都至少有 1-2 项中高风险
- 不要把"对策"写成"加强管理 / 提高重视" —— 必须具体动作
- 不要漏写"残余风险"
- 不要把第 7 章与第 6.6 敏感性割裂（高敏因子 → 高风险）
