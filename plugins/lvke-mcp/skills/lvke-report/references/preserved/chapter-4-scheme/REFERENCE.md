# 第 4 章 · 总体建设方案 起草

第 4 章把"项目要做多大"（第 3 章）落到"怎么做"。是最厚的一章（占全报告 25-35% 篇幅），评审专家最深入的章节。**所有数字（占地、人员、工期、设备）都在这章首次出现并被后续 5/6 章引用**。

## 必含 8 节（典型）

### 4.1 选址方案

要素：
- 选址原则（区位、配套、土地性质）
- 备选地址比较（≥2 个备选 + 加权评分）
- 推荐方案 + 论证理由
- 推荐选址条件：经纬度、行政区、面积、土地性质
- 周边环境敏感目标半径分析（学校 / 医院 / 居民区 / 文物）

### 4.2 工艺技术方案

要素：
- 工艺路线选型（≥2 路线比选 + 推荐）
- 工艺成熟度（已商用 / 中试 / 实验）
- 关键工艺参数（产能、能耗、原料配比、收率）
- 工艺流程图（文字描述 + 引用附图）
- 主要原辅材料消耗定额
- 三废产生量（环评依据）

### 4.3 主要设备方案

要素：
- 主要设备清单（按工序分组）
- 设备规格 / 型号 / 数量
- 关键设备来源（国产 / 进口 / 自制）
- 备用 / 冗余设备
- 关键设备的供货周期 / 进度匹配

⚠️ 设备清单要与第 5 章设备投资 cost 估算条目对应。

### 4.4 公用工程方案

要素：
- 给排水方案（水量、水源、排水标准）
- 供电方案（用电负荷、电源、备用电源）
- 供热 / 供气方案
- 暖通方案
- 通信方案
- 安全 / 消防

### 4.5 总图运输方案

要素：
- 总平面布置（功能分区、间距、交通组织）
- 厂内运输（车流、人流、物流分离）
- 厂外运输（与外部道路 / 铁路 / 水运的衔接）
- 紧急疏散 / 救援通道

### 4.6 土建工程方案

要素：
- 总建筑面积（地上 / 地下）
- 主要建筑物清单（用途、面积、结构形式、层数）
- 建筑标准 / 抗震设防
- 占地面积 / 建筑密度 / 容积率 / 绿地率

### 4.7 节能 / 环保方案

要素：
- 节能方案（用能结构、节能措施、能耗指标）
- 节水方案
- 三废处理方案（废气 / 废水 / 固废）
- 噪声 / 辐射 / 振动控制
- 环境管理体系

⚠️ 要与节能审查 / 环评报告衔接（不替代但要呼应）。

### 4.8 项目实施进度

要素：
- 进度表（按月或季度）
- 关键节点：审批完成、开工、主设备到货、单机试车、联动试车、达产
- 关键路径标识
- 进度的不确定性因素（审批 / 用地 / 设备进口）
- 总建设期（与 5.5 / 6.x 一致）

## 方案比选 4 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 选址比选 | 至少 2 备选 + 加权评分 + 推荐论证 |
| 2 | 工艺比选 | 至少 2 路线 + 比较表 + 推荐论证 |
| 3 | 设备比选 | 关键设备至少国产 / 进口对比 |
| 4 | 不"假比选" | 不能写"经比较 A 优于 B"无具体维度 |

## 数据一致性 6 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 占地 | 4.1 / 4.6 一致 |
| 2 | 建筑面积 | 4.6 各建筑物加总 = 总建筑面积 |
| 3 | 产能 | 4.2 工艺参数与第 3 章规模一致 |
| 4 | 人员 | 与第 5 章估算依据 / 第 6 章财评一致 |
| 5 | 建设期 | 4.8 与第 1 / 5 / 6 章一致 |
| 6 | 三废 | 与环评报告一致（若环评先做） |

## 常见缺陷

1. **方案比选走形式** —— 写了 A 和 B，但 B 明显是陪跑（数据明显不利）
2. **设备清单不完整** —— 漏关键设备 → 第 5 章投资估算少算
3. **工艺成熟度模糊** —— 不说工艺商业化年限、参考项目
4. **节能 / 环保偷懒** —— 只写"加强节能 / 严格环保"无具体措施
5. **进度过乐观** —— 关键路径 buffer 不足
6. **公用工程缺细节** —— 用电用水用气负荷估算缺依据

## 起草工作流

```
1. report_list_sections + report_get_section section_id=<第3章对应的 section_id>  → 知道规模
2. [调研 / 与项目方确认]：工艺路线、设备清单、用地
3. 起草 4.1 选址（含周边敏感目标分析）
4. 起草 4.2 工艺（含比选）
5. 起草 4.3 设备 → 与 5 章联动准备
6. 起草 4.4-4.7 配套
7. 起草 4.8 进度（关键路径）
8. report_propose_section 整章 → diff → apply
```

## 配套 skill

- `industry-context-*`：行业工艺 / 设备语境
- `policy-compliance-environmental` / `land-use`：4.1 选址 / 4.7 环保合规
- `report-drafting-chapter-5-investment`：4 章设备 → 5 章投资
- `doc-review-numerics-cross-check`：核对 6 项数据一致性

## 关键避免

- 不写"采用先进工艺" —— 说清楚先进在哪
- 不让设备清单泛化（"主要生产设备 1 套"无型号无数量）
- 不在 4.4 公用工程随手定能耗 —— 单耗有依据
- 不在 4.8 进度只画甘特图不写关键路径文字说明
