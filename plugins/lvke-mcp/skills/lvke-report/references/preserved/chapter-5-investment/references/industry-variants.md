> 各行业要点经'国家发改委大纲 + 绿科多年沉淀'提炼,具体数字以本项目实际为准。

## 新能源

- 建设投资按工程构成分：组件 + 逆变器 + 支架 + 升压站 + 接入 + 土建 + 监控
- 单位千瓦造价取行业 baseline（光伏 2.5-3.5 元/W、风电 6-8 元/W、储能 1.5-2.0 元/Wh）
- 建设期 6-18 个月,通常无价差预备费

## 房产建筑

- 建设投资按建安工程费 + 设备购置 + 工程建设其他费 + 预备费
- 建安单方造价取本地《建设工程造价信息》近期数据(住宅 3000-5500 元/㎡)
- 土地获取费(出让金/划拨补偿)单列,有依据文件

## 教育

- 建设投资按教学楼/宿舍楼/食堂/运动场分类列出
- 单方造价：教学楼 3500-4500、宿舍 2800-3500、食堂 3500-4500 元/㎡
- 实训设备购置费要按专业群单独列,有报价依据

## 医疗卫生

- 建设投资按门诊楼/医技楼/住院楼/特殊用房分类
- 单方造价远高于一般建筑(三甲医院综合 8000-12000 元/㎡)
- 医疗设备购置占比常达 25-40%,要列大型设备清单

## 路桥工程

- 建设投资按路基 + 路面 + 桥涵 + 隧道 + 交通工程 + 沿线设施 + 征地拆迁分项
- 单位公里造价取湖北省同等级公路近期数据
- 征地拆迁专门测算,有政府文件支撑

## 农林牧渔

- 建设投资按土地整理 + 灌溉/水利 + 道路 + 设施 + 加工设备分项
- 高标准农田类参考省财政厅亩均投入标准(湖北约 2000-3000 元/亩)
- 设施农业类温室造价波动大(连栋温室 500-1500 元/㎡)

## 物流仓储

- 建设投资按土地 + 主体仓库 + 制冷/特殊设施 + 信息化 + 设备
- 普通钢结构仓库 1000-1500 元/㎡，冷库 2500-4000 元/㎡
- AGV/立体库类信息化投入占比高

## 新兴产业

- 建设投资按厂房 + 工艺设备 + 公辅 + 信息化分项
- 工艺设备占比 50-70%,要逐项列报价或同类参考
