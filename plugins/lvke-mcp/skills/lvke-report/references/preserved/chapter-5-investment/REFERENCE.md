# 第 5 章 · 投资估算与资金筹措 起草

第 5 章把第 4 章的"怎么做"折算成"多少钱"。是评审专家最容易挑刺的章节，**所有数字必须有依据、有明细、有对照**。一旦数字与第 4 章设备清单或第 6 章财务分析不一致，全报告失分。

## 必含 6 节（典型）

### 5.1 估算依据

要素：
- 估算方法（指标估算 / 类比 / 概算定额）
- 主要参考定额（如《建筑工程概算定额》、《机电安装工程预算定额》）
- 价格水平（基准年 / 含税与否 / 汇率）
- 编制深度（可研深度 ±15%~20%）
- 重要假设条件

⚠️ 必须写明价格基准年（如"按 2025 年第 4 季度市场价"），否则后续无法判断合理性。

### 5.2 建设投资估算

要素（按工程构成分类）：
- 工程费用
  - 建筑工程费（土建）
  - 设备及工器具购置费（与第 4.3 设备清单一一对应）
  - 安装工程费
- 工程建设其他费
  - 土地使用费 / 拆迁补偿
  - 项目管理费
  - 勘察设计费
  - 咨询服务费（含可研编制费）
  - 工程监理费
  - 招标代理费
  - 联合试运转费
- 预备费
  - 基本预备费（一般 5-10%）
  - 价差预备费（建设期长 ≥ 2 年才需考虑）
- 建设期利息（若部分资金为借贷）

⚠️ 设备购置费要与第 4.3 设备清单逐项对应；任何漏项都会被发现。

### 5.3 流动资金估算

要素：
- 估算方法（扩大指标 / 分项详细估算）
- 流动资产构成（原材料 / 在产品 / 产成品 / 应收账款 / 现金）
- 流动负债构成（应付账款 / 应付工资 / 应付税金）
- 周转天数依据
- 流动资金 = 流动资产 - 流动负债
- 铺底流动资金（一般 30%）

### 5.4 总投资构成

要素：
- 总投资 = 建设投资 + 建设期利息 + 流动资金
- 三表（按工程构成 / 按费用性质 / 按出资人）汇总
- 单位投资指标（元/平方米、元/吨产能等）—— 便于行业类比

### 5.5 资金筹措方案

要素：
- 资金来源构成（自有资金 / 银行贷款 / 政府补贴 / 债券 / 其他）
- 各来源占比（一般自有资金 ≥ 30%）
- 贷款条件（额度 / 期限 / 利率 / 还款方式）
- 增信措施（抵押 / 担保 / 政府背书）
- 资金到位时间

⚠️ 资本金比例必须符合《国务院关于固定资产投资项目试行资本金制度的通知》最新规定（不同行业最低 20%-40%）。

### 5.6 资金使用计划

要素：
- 按建设期月份 / 季度分配的资金计划表
- 与第 4.8 进度的匹配性
- 高峰资金需求月（融资风险点）
- 资金使用与回收节奏

## 数据一致性 7 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 设备购置费 | 与 4.3 设备清单逐条对应 |
| 2 | 总建筑面积 | 5.2 土建费用单价 × 4.6 面积 ≈ 土建工程费 |
| 3 | 工程费小计 | 各分项加和 = 总工程费 |
| 4 | 总投资公式 | 总投资 = 建设投资 + 建设期利息 + 流动资金 |
| 5 | 资金来源 | 自有 + 借贷 + 其他 = 总投资 |
| 6 | 资本金比例 | 满足行业最低要求 |
| 7 | 资金使用计划 | 与 4.8 进度一致 |

## 单位投资指标 行业参考

| 行业类型 | 单位投资 |
|---|---|
| 一般工业 | 4000-15000 元/m² 建筑面积 |
| 化工 | 8000-30000 元/m²（高端工艺更高） |
| 数据中心 | 30000-80000 元/m² |
| 物流仓储 | 2000-5000 元/m² |
| 公共建筑 | 5000-15000 元/m² |
| 道路工程 | 2000-8000 元/m（不同等级） |

⚠️ 单位投资指标差异巨大，**不要直接跨行业类比**；提供指标只是粗筛工具。

## 常见缺陷

1. **设备清单与投资估算脱节** —— 4.3 设备 10 项，5.2 设备投资只有 7 项明细
2. **价格基准年漏写** —— 评审无法判断是 5 年前价还是当前价
3. **预备费比例失常** —— 建设期 ≤ 1 年还算价差预备费 → 浮夸
4. **资本金比例不合规** —— 写 25% 但行业要求 30%
5. **流动资金估算缺依据** —— 直接写"按总投资 10%"，未做分项
6. **资金来源不到位证明缺失** —— 只说"银行贷款 1 亿"无意向函或承诺书
7. **资金使用与建设进度倒挂** —— 第 1 季度需要 60% 资金但融资 6 月才到位

## 关键避免

- 不要把"预备费"和"基本预备费 + 价差预备费"概念混用
- 不要在 5.5 资金来源忽略政府投资 / 财政贴息（湖北项目常见）
- 不要让"建设期利息"成为黑箱 —— 必须列明计算公式
- 不要让单位投资指标做最后判断 —— 只是粗筛
