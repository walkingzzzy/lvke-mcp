# 第 3 章 · 需求分析与建设规模 起草

第 3 章决定**项目"做多大"是否合理**。投资规模、产能配置、回收期都跟着这一章走。本章数据如果偏乐观，后续财评数字全部偏高。

## 必含 4 节

### 3.1 市场需求分析

**4 维度需求测算**：

1. **总量需求**：行业总需求量（年）+ 测算方法 + 数据来源
2. **结构需求**：按用途 / 客户类型 / 区域细分需求
3. **趋势预测**：未来 5-10 年增长率（带情景：保守 / 中性 / 乐观）
4. **替代品威胁**：是否有替代技术 / 产品挤压需求

**4 种测算方法**（选 1-2 种用，互相印证）：

| 方法 | 适用 | 数据要求 |
|---|---|---|
| 趋势外推 | 数据足够长（≥5 年）+ 行业稳定 | 历史数据 |
| 行业增长率法 | 行业有官方增长率预测 | 行业研报 / 协会 |
| 类比法 | 选标杆地区 / 标杆国家类比 | 类似地区数据 |
| 自下而上法 | 主要客户名单 + 各客户需求量 | 客户调研 |

### 3.2 市场供给分析

要素：
- 现有供给能力总量
- 主要竞争对手（产能、市场份额、产品定位）
- 新增供给（在建 / 拟建项目清单）
- 进口替代情况（如有）

**供需缺口表**：

| 年份 | 需求 | 供给 | 缺口 | 本项目供给 | 缺口填补率 |
|---|---|---|---|---|---|
| YYYY | XX | XX | XX | XX | XX% |
| ... | | | | | |

### 3.3 建设规模论证

**3 步法**：

1. **基础规模**：基于市场缺口 × 本项目可获份额
2. **修正规模**：技术 / 经济 / 政策约束修正
   - 技术经济规模：行业最小经济规模（如水泥行业 4000t/d 起）
   - 用地约束：地块大小
   - 资金约束：投资上限
   - 用工约束：当地用工承载
3. **最终规模**：综合论证后的推荐规模

**关键技巧**：
- 给出"规模—投资—收益"敏感性分析 → 解释为何选定这个规模
- 不要写"经反复论证，选 XX 规模"而无过程

### 3.4 产品 / 服务方案

要素：
- 产品 / 服务类型（含规格、等级、用途）
- 产能配比（如多产品时各占比）
- 副产品 / 废弃物处置方案概述
- 产品标准 / 质量等级（引用 GB / 行业标准）
- 销售策略概述（详见后续章节）

## 数据使用 5 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 数据时效 | 引用最近 18 个月内的官方数据 |
| 2 | 数据来源 | 注明具体出处（国家统计局、行业协会、研报机构 + 时间） |
| 3 | 口径一致 | 同一指标在不同段落用同一口径（同样的"市场需求"定义） |
| 4 | 量级合理 | 与行业 baseline 检验，量级合理 |
| 5 | 区分实测 vs 推算 | 哪些是直接数据，哪些是模型推算，标明 |

## 规模合理性 6 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 经济规模 | 至少达到行业最小经济规模 |
| 2 | 缺口填补 | 本项目占新增缺口 ≤ 30%（避免一项目独大） |
| 3 | 用地匹配 | 与已获 / 拟获用地规模匹配 |
| 4 | 资金匹配 | 与建设单位融资能力匹配 |
| 5 | 工艺匹配 | 与拟选工艺最佳生产规模匹配 |
| 6 | 进度合理 | 建设期能在市场窗口内完成 |

## 常见缺陷

1. **测算过乐观** —— 用最新一年高峰数据当 baseline，未来 10 年线性外推
2. **缺供给侧** —— 只写需求，不写现有供给与新增供给
3. **规模随手定** —— "考虑到 XX，建设 100 万吨" 缺论证
4. **副产品缺失** —— 不写副产品 / 废弃物处置 → 环评章节漏洞
5. **方法堆砌** —— 4 种方法都用一遍但没说哪个为准

## 起草工作流

```
1. report_list_sections → 拿项目背景
2. [调研]：mcp-statistics-cn / mcp-industry-research / web_search
3. 选 1-2 种测算方法，把数据带回来
4. 画供需缺口表
5. 走规模 3 步法
6. 写 4 节
7. report_propose_section → diff → apply
```

## 关键避免

- 不引"市场前景广阔"这种无数据的描述
- 不让规模数字独自存在 —— 必须配论证链
- 不写"考虑各种因素，最终确定 XX 规模" —— 因素要列出
- 不在 3 章给最终财务结论 —— 留给 6 章
