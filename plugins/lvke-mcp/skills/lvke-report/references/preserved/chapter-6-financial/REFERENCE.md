# 第 6 章 · 财务分析与评价 起草

第 6 章是评审委员会决定"项目能不能投"的核心证据。**所有指标必须有公式、有依据、有可重算的计算表**。一旦 IRR / NPV 与第 5 章总投资或第 4 章规模不一致，全章作废。

## 必含 7 节（典型）

### 6.1 财务评价依据

要素：
- 评价方法（《建设项目经济评价方法与参数》第 3 版）
- 计算期（建设期 + 运营期 = 总计算期，一般 15-25 年）
- 折现率（行业基准收益率 / 企业要求收益率）
- 价格水平、汇率、税率假设
- 是否含税 / 含通胀

### 6.2 营业收入估算

要素：
- 产品 / 服务定价依据（市场价 / 政府定价 / 议价能力）
- 产销率假设（投产年 / 达产年）
- 收入 = 销量 × 单价 = f(规模, 产能利用率, 价格)
- 销售税费扣减
- 收入预测表（按运营年）

⚠️ 价格波动假设要保守。**不要按当前最高价拍头**。

### 6.3 成本费用估算

要素：
- 总成本 = 经营成本 + 折旧 + 摊销 + 财务费用
- 经营成本 = 直接材料 + 直接人工 + 燃料动力 + 制造费用 + 管理费用 + 销售费用
- 固定成本 vs 变动成本 拆分（敏感性分析依据）
- 折旧：直线法 / 加速法，年限按行业规则
- 摊销：无形资产、长期待摊费用
- 财务费用：建设期利息已资本化的部分不计入

### 6.4 利润与利润分配

要素：
- 利润总额 = 收入 - 成本 - 税金及附加
- 所得税（15% 高新 / 25% 普通 / 行业税收优惠）
- 净利润分配（公积金 / 公益金 / 股东分红）
- 累计可分配利润 / 未分配利润表

### 6.5 现金流量分析

要素：
- 项目现金流（IRR / NPV 用）
  - 流入：营业收入 + 回收固定资产余值 + 回收流动资金
  - 流出：建设投资 + 流动资金 + 经营成本 + 销售税金 + 所得税
- 资本金现金流（股东收益率用）
  - 在项目现金流基础上扣除借贷本息
- 关键指标
  - 项目 IRR / NPV / 静态投资回收期 / 动态投资回收期
  - 资本金 IRR / NPV
  - 投资利润率 / 投资利税率 / 资本金利润率

### 6.6 不确定性分析

要素：
- 盈亏平衡分析（BEP）
  - 量盈亏平衡点
  - 价盈亏平衡点
  - 安全裕度
- 敏感性分析（单因素）
  - 至少 5 个因子：销售收入、经营成本、建设投资、产能利用率、销售价格
  - 变化区间 ±10% / ±20%
  - 敏感性图 / 表 → IRR 弹性
- 概率分析（蒙特卡洛，可选）

⚠️ 见 `financial-modeling-sensitivity` 详细规则。

### 6.7 财务评价结论

要素：
- 项目 IRR vs 行业基准收益率（高 / 持平 / 低）
- 投资回收期 vs 行业典型水平
- 敏感性分析结论（哪个因素最敏感）
- 综合财务可行性判断

## 计算可重算性 8 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 计算期 | 总计算期 = 建设期 + 运营期 一致 |
| 2 | 折现率 | 与依据章节声明的一致 |
| 3 | 投资 | 与 5.4 总投资一致 |
| 4 | 折旧 | 折旧年限 + 残值率 列明 |
| 5 | IRR 公式 | NPV = Σ CFi / (1+IRR)^i = 0 → 验算 |
| 6 | 投资回收期 | 累计现金流符号变化点（含动态） |
| 7 | 敏感性 | 至少 5 因子，IRR 变化弹性 |
| 8 | 单元一致 | 同一表内 元/万元/亿元 统一 |

## 关键指标参考阈值

| 指标 | 一般工业项目 | 公共项目 | 房地产 | PPP |
|---|---|---|---|---|
| 项目 IRR（税后） | ≥ 8-10% | ≥ 5-8% | ≥ 12-15% | 看协议约定 |
| 投资回收期 | ≤ 10-15 年 | ≤ 25 年 | ≤ 8 年 | 看协议 |
| 资本金 IRR | ≥ 10-15% | ≥ 8-10% | ≥ 15-20% | ≥ 6-8% |

⚠️ 行业阈值仅供参考。**评审最看重的是 IRR vs 行业基准**，不是绝对值。

## 常见缺陷

1. **IRR 算错** —— 现金流符号错（折旧错算成现金流出）
2. **没区分项目 IRR 和资本金 IRR** —— 用项目 IRR 论证股东收益
3. **敏感性分析只做一个因子** —— 必须 ≥ 5 因子
4. **价格假设过于乐观** —— 按当前最高价拍头未做下行情景
5. **折旧不写清方法和年限** —— 评审无法验算
6. **建设期利息处理错** —— 资本化 vs 费用化口径不一
7. **税率假设错** —— 用普通税率忽略行业优惠或反之
8. **没做盈亏平衡** —— 缺少 BEP 安全裕度

## 关键避免

- 不要在 6.5 写"项目内部收益率为 12.5%" 而无现金流表附后
- 不要把"折旧"算成"现金流入"
- 不要让 5 个敏感性因子全部走 ±10% —— 用业内合理波动幅度
- 不要让基准收益率与行业脱节（不能用 5% 评一般工业项目）
