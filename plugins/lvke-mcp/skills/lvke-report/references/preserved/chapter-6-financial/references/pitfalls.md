# 常见错误清单 · report-drafting/chapter-6-financial

## 口径错误

- 项目 IRR 现金流含借贷利息(全投资假设下不应含)
- 末年没含残值和流动资金回收
- 折旧/摊销算作现金流出(已通过利润扣除体现)
- 敏感性基准列 IRR 与 6.5 节基准 IRR 数字不一致
- 盈亏平衡分析用错口径(销售量盈亏 vs 经营成本盈亏)

## 假设错误

- 贴现率与行业 baseline 偏离过大(无解释)
- 经营成本固定/可变拆分错误
- 所得税率默认 25% 不区分高新技术企业 15%
