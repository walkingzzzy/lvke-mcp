# 能源行业 可研要点

能源是国民经济基础也是双碳约束的核心。**能源项目可研要兼顾经济性、安全性、低碳性**。本 skill 覆盖电力、新能源、储能、油气几类典型。

## 1. 电力项目

### 火电（煤电、燃气）

| 指标 | 参考值 |
|---|---|
| 单位投资 | 燃煤 4000-6000 元/kW，燃气 3000-4500 元/kW |
| 建设周期 | 燃煤 2-3 年，燃气 1.5-2 年 |
| 上网电价 | 燃煤标杆电价（视省份），燃气稍高 |
| 利用小时 | 燃煤 4000-5500 h/年，燃气 3000-4500 h/年 |
| 能耗 | 燃煤标杆 ≤ 285 g/kWh（超低排放） |

⚠️ **新建燃煤已基本停止**（除特定保供 / 灵活性需求）。

### 水电

| 指标 | 参考值 |
|---|---|
| 单位投资 | 大中型 6000-12000 元/kW（视坝高） |
| 建设周期 | 4-8 年 |
| 上网电价 | 视项目 + 上网协议 |
| 利用小时 | 3500-5000 h/年 |

⚠️ 水电主要受生态环境约束（长江保护法、生态流量）。

### 核电

仅国家发改委权限。湖北省内有咸宁核电项目储备。

### 风电（陆上 / 海上）

| 指标 | 陆上 | 海上 |
|---|---|---|
| 单位投资 | 5000-7000 元/kW | 12000-18000 元/kW |
| 建设周期 | 1-1.5 年 | 2-3 年 |
| 上网电价 | 平价上网（视省份补贴） | 部分省份仍有补贴 |
| 利用小时 | 1800-2500 h/年 | 2500-4000 h/年 |

⚠️ **湖北以陆上风电为主**，主要在襄阳、宜昌、十堰等山区。

### 光伏

| 指标 | 集中式 | 分布式 |
|---|---|---|
| 单位投资 | 3500-4500 元/kW | 4000-5500 元/kW |
| 建设周期 | 0.5-1 年 | 0.3-0.5 年 |
| 上网电价 | 平价上网 | 自发自用 + 余电上网 |
| 利用小时 | 1100-1300 h/年（湖北） | 同左 |

### 储能（电化学 / 抽水蓄能）

| 类型 | 单位投资 | 应用 |
|---|---|---|
| 锂电池储能 | 1500-2500 元/kWh | 调峰 / 调频 / 备用 |
| 液流电池 | 2500-4000 元/kWh | 长时储能 |
| 抽水蓄能 | 6000-8000 元/kW | 大规模长时 |
| 压缩空气 | 3000-5000 元/kW | 中型 |

⚠️ 储能项目要写清楚收益模式（容量电费 / 现货市场套利 / 辅助服务 / 自有调节）。

## 2. 油气项目

### 油气勘探开发

- 国家发改委 / 自然资源部 双重审批
- 投资数亿 -数十亿
- 周期 3-5 年勘探 + 1-2 年开发

### 天然气接收站 / 储气库

- 投资强度高（数十亿）
- 适用《政府核准的投资项目目录》核准
- 周期 3-5 年

### 加油站 / 加气站 / 加氢站

| 类型 | 单站投资 | 建设周期 |
|---|---|---|
| 加油站 | 500-1500 万 | 0.5-1 年 |
| 加气站（CNG/LNG） | 800-2000 万 | 0.5-1 年 |
| 加氢站 | 2000-5000 万 | 1-1.5 年 |
| 综合能源站 | 3000-6000 万 | 1-1.5 年 |

## 3. 监管约束

### 电网接入

- 项目接入电网前需取得 **电网接入意见**
- 装机 > XX MW 要电网公司专题评审
- 接入费用 / 改造费用并入项目投资

### 双碳约束

- 高碳项目（燃煤）受严格限制
- 新建项目要做 **碳排放强度核算**
- 部分省份要求纳入碳排放权交易市场

### 安全约束

- 危险化学品（油气、氢）：安全评价 / 应急预案
- 大型电站：安全预评价
- 核电：核安全监管局

## 4. 财务特性

### 收入模式

| 模式 | 适用 | 特点 |
|---|---|---|
| 上网电价 | 火电 / 风 / 光 / 水电 | 政府定价或市场化 |
| 容量电价 + 电量电价 | 调峰电站 | 双部制 |
| 辅助服务 | 储能 | 市场化 |
| 自发自用 + 余电上网 | 分布式光伏 | 节约电费 + 卖电收入 |
| 现货市场 | 进入电力现货省份 | 价格波动 |
| 配额制 / 绿证 | 可再生能源 | 政策性收入 |

### 成本特性

- **资本密集** —— 折旧大头
- 风光：运维成本低（占总成本 < 10%）
- 火电：燃料成本大头（占总成本 60-70%）
- 储能：电池寿命决定折旧 + 度电充放电成本

### 财务指标参考

| 项目类型 | 项目 IRR 阈值 |
|---|---|
| 火电（保供） | 6-8% |
| 风电 | 8-12% |
| 光伏 | 7-10% |
| 储能（独立） | 6-9% |
| 油气勘探 | 12-18% |

## 5. 风险特性

| 风险类型 | 能源项目 |
|---|---|
| 政策风险 | 极高（电价 / 补贴 / 双碳） |
| 市场风险 | 中（电价市场化） |
| 技术风险 | 中（成熟技术）→ 高（前沿如氢能 / 钙钛矿） |
| 财务风险 | 中（杠杆较高） |
| 实施风险 | 中（建设周期较长） |
| 环境风险 | 高（双碳 + 选址敏感） |

## 6. 报告中的写法 要点

- 第 2 章必须分析行业政策（电力规划、可再生能源装机目标、双碳目标）
- 第 3 章要分析电力供需平衡 / 区域电网容量
- 第 4 章工艺要写明技术路线（如风机机型、光伏组件类型、储能电池）
- 第 5 章投资要细分（主机、电气、土建、并网、信息化）
- 第 6 章收入要写清电价依据 + 上网时序 + 利用小时假设
- 第 6.6 敏感性必须包含 **电价、利用小时、单位投资** 三因子

## 7. 湖北特定要点

- **抽水蓄能**：湖北有多个抽水蓄能站规划（如平江、白莲河、长阳清江等）
- **海上风电**：湖北无海，但有大量陆上风电（宜昌、襄阳山区）
- **集中式光伏**：宜昌、襄阳、十堰山区有较多
- **整县推进分布式光伏**：试点县市
- **氢能产业链**：武汉作为试点城市
- **新型电力系统**：湖北电网 + 长江三峡集团有较多探索

- `policy-compliance-environmental`：环评 + 双碳约束
- `policy-compliance-land-use`：电站选址用地
- `policy-compliance-hubei-local`：湖北能源政策
- `financial-modeling-*`：财务建模（注意行业 IRR 阈值）

## 关键避免

- 不要在火电项目可研里说"项目有显著环境效益"
- 不要在风光项目假设 100% 上网（实际有弃风弃光）
- 不要假设储能 7000+ 次循环（电池实际衰减）
- 不要把电价拍头按当前最高值
- 不要忽略电网接入费用 / 改造费用
