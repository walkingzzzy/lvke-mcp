# 制造业 可研要点

制造业是湖北"51020"产业体系的核心。**评审重点是技术先进性、市场竞争力、产业链协同**。本 skill 覆盖湖北重点制造领域。

## 1. 一般机械制造

### 单位投资参考

| 子领域 | 投资强度 |
|---|---|
| 普通机械 | 1500-4000 元/m² 厂房 |
| 数控机床 | 2000-5000 元/m² 厂房 |
| 重型机械 | 2500-6000 元/m² 厂房 |
| 工程机械 | 2000-5000 元/m² 厂房 |
| 精密仪器 | 4000-10000 元/m² 厂房（含洁净环境） |

### 关键设备

- 数控加工中心（卧加 / 立加 / 五轴）
- 焊接机器人
- 检测设备（三坐标测量 / 影像仪）
- 表面处理（喷涂 / 阳极氧化 / 电镀）

⚠️ 进口设备 vs 国产 → 投资 + 周期 + 关税差异巨大。

### 产能定义

- 班次（单班 / 双班 / 三班）
- 节拍（设备每小时产出）
- 工时利用率（一般 70-85%）
- 产品合格率（影响有效产能）

## 2. 电子信息制造

### 单位投资参考

| 子领域 | 投资强度 |
|---|---|
| 通用电子（PCBA、电子产品） | 3000-8000 元/m² 厂房 |
| 半导体（封测） | 1.5-3 万元/m²（含洁净 + 厂务系统） |
| 集成电路（晶圆制造） | 数十亿至数百亿/线（按工艺节点） |
| 显示器件（OLED / LCD） | 数十亿/线 |
| 锂电池 | 1.5-3 亿元/GWh |

⚠️ 半导体 / 显示 / 锂电池属于资本密集型，**投资量级与一般制造完全不同**。

### 关键约束

- **洁净度等级**：千级 / 百级 / 十级（每等级投资数倍增长）
- **关键设备进口**：光刻机、刻蚀机等（地缘风险）
- **化学品供应**：高纯度气体 / 化学品（多依赖进口）
- **水电气稳定**：长时间停电 / 停水会导致重大损失

### 湖北特点

- **武汉光谷**：光通信、半导体显示、集成电路（长江存储等）
- **武汉、襄阳**：汽车电子
- **黄石、咸宁**：PCB 与电子元器件

## 3. 化工与原材料

### 单位投资参考

| 子领域 | 投资强度 |
|---|---|
| 基础化工（合成氨、烧碱） | 5000-15000 万/万吨 |
| 化工新材料 | 1-5 亿/万吨（视品种） |
| 高端精细化工 | 2-10 亿/万吨 |
| 涂料 / 油墨 | 2000-5000 万/千吨 |
| 农化（农药 / 化肥） | 3000-8000 万/万吨 |

### 监管约束（化工尤其严）

- **化工园区**：化工项目必须落地化工园区（湖北重要园区：宜昌姚家港、潜江、武汉化工区等）
- **安评 + 应急**：危化品项目必做
- **环评**：基本都是报告书
- **双重防控**：风险分级管控 + 隐患排查治理
- **化工产业结构调整**：淘汰落后产能
- **长江沿岸 1km 内**：禁止新建化工项目

### 投资构成 特点

- 主装置投资占比 50-60%
- 公用工程 / 厂务系统占 20-30%
- 安全 / 环保设施占 8-12%
- 库区 / 罐区独立

## 4. 医药 / 大健康

### 单位投资参考

| 子领域 | 投资强度 |
|---|---|
| 化学原料药 | 1-3 亿/百吨 |
| 制剂（片剂 / 胶囊） | 3000-8000 万/亿粒 |
| 生物制药 | 数亿至数十亿/万升发酵 |
| 中成药 | 5000-15000 万/亿粒 |
| 医疗器械 | 5000-20000 万/产线 |

### 监管约束

- **GMP 认证**：药品生产必须通过
- **临床试验**：新药 I / II / III 期，周期数年
- **NMPA 注册**：药品 / 器械上市必备
- **HACCP / ISO 13485**：医疗器械
- **细胞治疗 / 基因治疗**：特别管理

### 湖北特点

- **武汉光谷生物城**：全国领先生物医药基地
- **荆门 / 黄冈 / 仙桃**：医疗器械（如新冠期间口罩与防护服）
- **武汉、襄阳**：中药材深加工

## 5. 汽车制造

### 单位投资参考

| 子领域 | 投资强度 |
|---|---|
| 整车厂（30 万辆/年） | 100-200 亿（含冲压 / 焊装 / 涂装 / 总装） |
| 新能源汽车（同规模） | 80-150 亿 |
| 三电系统 | 8-20 亿/线 |
| 动力电池 | 1.5-3 亿/GWh |
| 汽车零部件 | 5000-30000 万/项目 |

### 关键能力

- 冲压 / 焊装 / 涂装 / 总装 四大工艺
- 供应链协同（一般要求供应商集群 ≤ 300km）
- 售后服务网络
- 数字化 / 智能化

### 湖北特点

- **武汉、襄阳、十堰、随州、孝感**：东风系完整产业链
- **新能源汽车**：东风岚图、东风猛士、小米武汉超级工厂等
- **零部件**：襄阳 / 黄石 / 鄂州集群

## 6. 新材料

### 子领域

| 类型 | 典型 |
|---|---|
| 高性能金属 | 钛合金、铝合金、镁合金 |
| 先进无机 | 陶瓷、玻璃、特种纤维 |
| 高分子 | 聚酰胺、聚酯、特种橡胶 |
| 复合材料 | 碳纤维 / 玻璃钢 |
| 电子化学品 | 高纯气体、湿电子化学品 |

### 投资特点

- 资本密集
- 技术壁垒高
- 研发投入大（≥ 销售额 5-10%）
- 客户认证周期长（汽车 / 半导体 / 航空航天客户认证 2-3 年）

## 7. 财务特性

### 收入

- 销售价格通常市场化（除部分垄断性产品）
- 客户集中度高 → 议价能力影响利润率
- 出口 vs 内销 → 汇率影响

### 成本

- 直接材料 / 直接人工占比按行业差异
- 半导体 / 化工：原材料 / 化学品占比 50-70%
- 装配型：人工占比相对高
- 折旧：资本密集型大头

### 财务指标参考

| 行业 | 项目 IRR 阈值 | 毛利率 |
|---|---|---|
| 一般机械 | 10-15% | 15-25% |
| 电子（一般） | 12-18% | 15-25% |
| 半导体 | 10-15% | 30-50% |
| 化工（基础） | 8-12% | 15-25% |
| 化工新材料 | 12-18% | 25-40% |
| 医药制剂 | 15-20% | 50-70% |
| 整车制造 | 8-15% | 8-20% |
| 汽车零部件 | 10-18% | 15-30% |

## 8. 风险特性

| 风险 | 制造业 |
|---|---|
| 政策风险 | 中（产业政策影响） |
| 市场风险 | 高（周期 / 价格 / 竞争） |
| 技术风险 | 高（更迭快） |
| 财务风险 | 中 |
| 实施风险 | 中（设备到货） |
| 环境风险 | 化工类极高，一般制造较低 |

## 9. 报告中的写法 要点

- 第 2 章必须分析行业现状 / 竞争格局 / 上下游
- 第 3 章产能利用率假设要保守（前 3 年爬坡 60%/80%/100%）
- 第 4 章工艺路线比选要写清（不同技术路线投资 / 性能差异）
- 第 5 章设备清单要细到型号
- 第 6 章产品定价要看竞品（不能拍头）
- 第 6.6 敏感性必须包含 **产品价格、原材料价格、产能利用率**
- 第 7 章必含 **技术更迭风险**、**产能过剩风险**

## 10. 湖北 "51020" 产业链

5 大优势：
1. 光电信息（半导体显示 / 光通信 / 集成电路）
2. 汽车制造与服务
3. 大健康（生物医药 / 医疗器械）
4. 现代化工与能源
5. 现代农产品加工

10 大新兴特色：
1. 集成电路
2. 新型显示
3. 智能制造装备
4. 商用航天与航空
5. 北斗
6. 网络安全
7. 数字创意
8. 新能源新材料
9. 节能环保
10. 现代物流

⚠️ 项目所属产业链需对照"51020"目录 → 享受相应优惠政策。

## 关键避免

- 不要把化工项目放在化工园区以外
- 不要在新能源汽车 / 电池假设循环寿命过高
- 不要把医药 GMP 投资估算太低
- 不要忽略电子洁净度对投资的放大
- 不要让产能利用率假设第 1 年就 100%
- 不要假设客户认证一蹴而就（汽车 / 半导体 2-3 年）
