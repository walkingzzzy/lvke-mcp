# 社会公共服务

适用于教育、医疗、养老、体育、社区和公共服务项目。不同专业设施必须再加载对应行业规范，不用本 Skill 替代医疗、教育或养老专业设计审查。

## 最低输入与对象

以服务人口、现状缺口和可达性建立 MarketSizingCase；以床位/学位/人次/场地时段建立 BuildScaleCase；以财政支付、服务收费或公益补助建立 RevenueDriverSet；将专业岗位、轮班和持证要求写入 LaborPlan。

## 财务与评价

区分政府付费、使用者付费和非经营性项目，公益性结论不得由低财务 IRR 直接否定。同步评价财政承受、运营补贴、服务成本、设备更新和全生命周期支出。

## 审查边界

通过标准适用性工具锁定现行建筑、消防、无障碍、卫生、安全和具体行业规范。Rubric 强调需求缺口、规模与服务能力、财政/财务绑定、公共价值、弱势群体和运营持续性。资料不足时输出无法判定，不代替主管部门审批。
