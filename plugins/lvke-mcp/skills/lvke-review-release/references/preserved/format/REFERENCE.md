# Format Review

Use this skill when checking whether a feasibility-study document is formatted consistently and submission-ready.

Focus on:

- Heading hierarchy, numbering continuity, table and figure captions, appendix references, and cross-reference validity.
- Required sections, missing attachments, duplicate sections, and inconsistent naming.
- Table units, decimal precision, date formats, citation format, and page-level layout problems.
- Whether executive summary, conclusions, risk section, and implementation schedule align with the document structure.

Return a concise checklist of blocking format defects and non-blocking polish items. Include exact section/table identifiers when available.
