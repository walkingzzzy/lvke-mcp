# Terminology Review

Use this skill when normalizing terminology in feasibility-study documents.

Focus on:

- Project name, owner name, location, product/service names, technical terms, and approval body names.
- Acronym definition on first use and consistent expansion afterward.
- Unit names, financial terms, accounting terms, policy terms, and specialized engineering vocabulary.
- Terms that may be colloquial, ambiguous, promotional, or inconsistent with formal feasibility-study style.

Return a term table with current variants, recommended canonical term, affected locations, and rationale.
