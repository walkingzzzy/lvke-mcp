# 环境合规 规范

环境审批是项目能否落地的硬约束之一。**未通过环评 → 项目不能开工 → 可研无意义**。本 skill 覆盖核心要点。

## 1. 环评分类（按 2024 年最新名录）

### 三类申报形式

| 形式 | 适用 | 周期 | 费用 |
|---|---|---|---|
| 编制环境影响报告书 | 重大环境影响项目 | 3-6 个月 | 30-100 万 |
| 编制环境影响报告表 | 轻度环境影响项目 | 1-2 个月 | 5-15 万 |
| 填报登记表 | 影响很小项目 | 即报即批 | 0 元（在线提交） |

⚠️ 分类直接对应**《建设项目环境影响评价分类管理名录》**最新版（生态环境部第 16 号令，2021 年 1 月施行，定期修订）。

### 重大项目分类

需编报告书的典型项目：
- 化工、医药、冶金、建材（产能限值以上）
- 火电、热电
- 大型矿山
- 危险废物利用处置
- 大型养殖场
- 重大基础设施（机场、铁路、高速公路、跨流域调水）

### 不需要环评的项目

- 不涉及生产排放
- 列入豁免清单（如个别社会事业项目）
- 但可能仍需备案

## 2. 双碳约束 速查

### 核心政策框架

- 《2030 年前碳达峰行动方案》（国发〔2021〕23 号）
- 各省"十四五"碳达峰实施方案
- 重点行业碳达峰行动方案（钢铁 / 建材 / 石化 / 有色 / 工业 / 城乡建设 / 交通 / 农业农村 / 公共机构）

### 高耗能行业准入

新建项目必须：
1. **能耗强度** ≤ 国家行业先进水平
2. **碳排放强度** ≤ 行业平均
3. **未列入限制 / 淘汰类**（看产业结构调整指导目录）

⚠️ 湖北省对重点用能行业有"两高一低"项目专项审核。

### 节能评估

固定资产投资项目能评必须做（2010 年 6 号令 + 2017 年发改委令 第 44 号 ）：
- **年综合能耗 ≥ 5000 吨标煤** → 单独节能审查
- **1000-5000 吨标煤** → 简化能评
- **< 1000 吨标煤** → 一般无需单独能评

## 3. 生态红线 / 永久基本农田

### 红线约束

新建项目原则上不得占用：
- **生态保护红线**（包括国家级 / 省级自然保护区核心区、缓冲区）
- **永久基本农田**
- **饮用水水源保护区**
- **重要湿地**

特殊情况：必须经过国务院 / 省政府严格审批（生态红线占补平衡 / 永久基本农田补划）。

### 占用审批层级

| 类型 | 审批层级 |
|---|---|
| 生态红线（核心区）占用 | 国务院 |
| 生态红线（一般控制区）占用 | 省政府 |
| 永久基本农田占用 | 国务院 |
| 一般耕地占用 | 省 / 市政府 |

## 4. 排污许可证

### 核心政策

- 《排污许可管理条例》（国务院令第 736 号，2021 年施行）
- 实施名录决定企业是否需要"持证排污"

### 分类

- **重点管理**：高污染行业
- **简化管理**：中度污染行业
- **登记管理**：低污染或无固定排污

⚠️ 报告中要说明本项目对应分类与申领时机。

## 5. 环境敏感目标识别

### 必须识别的敏感目标

| 类型 | 半径敏感区 |
|---|---|
| 居民区 | 500m-2km（视项目类型） |
| 学校 / 医院 | 1km-2km |
| 文物保护单位 | 200m-500m |
| 饮用水水源 | 视水源保护区一级 / 二级 / 准 |
| 自然保护区 | 视保护区分类 |
| 风景名胜区 | 视保护区分类 |
| 重要湿地 | 视湿地分类 |

⚠️ 选址报告必须列敏感目标距离表。

## 6. 报告写法

```markdown
### 4.X.Y 环境影响评价情况

**项目环评分类**：根据《建设项目环境影响评价分类管理名录》（2024 年版），
本项目属于 **X 类**，需编制 **环境影响报告书 / 报告表**。

**敏感目标识别**：

| 敏感目标 | 类型 | 与项目距离 | 影响等级 |
|---|---|---|---|
| XX 小学 | 教育 | 800 m | 中 |
| XX 河 | 水体 | 200 m | 高 |
| ... | ... | ... | ... |

**生态红线 / 基本农田情况**：
- 项目用地是否占用生态红线：否（已对照《湖北省生态保护红线划定方案》核实）
- 项目用地是否占用永久基本农田：否

**节能评估情况**：
- 预计年综合能耗：XXX 吨标煤
- 需独立节能审查 / 简化能评 / 无需能评：[X]

**双碳约束**：
- 项目能耗强度：X 吨标煤/万元 < 行业先进水平 X
- 项目碳排放强度：X 吨 CO₂/万元 < 行业平均 X

**环评进度安排**：
- 环评单位招标：M3
- 环评报告书编制：M4-M6
- 公示与受理：M7
- 评审与批复：M8
- 计划开工：M9
```

## 7. 数据一致性 5 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 环评分类 | 与名录对应 |
| 2 | 三废产生量 | 与 4.2 工艺方案一致 |
| 3 | 能耗 | 与 4.4 公用工程方案一致 |
| 4 | 选址 | 与 4.1 选址方案一致 |
| 5 | 进度 | 环评批复在开工前完成 |

## 8. 常见缺陷

1. **环评分类错** —— 拿《名录》上一版做对照
2. **遗漏敏感目标** —— 500m 内有学校但报告没列
3. **占用生态红线 / 基本农田未识别** —— 后期审批必退
4. **能评和环评混淆** —— 两个独立审批，节能审查不能替代环评
5. **双碳约束未识别** —— 高耗能项目未做能耗强度对标
6. **环评进度太晚** —— 计划开工早于环评批复

## 关键避免

- 不要写"项目通过环评" —— 环评是后续审批，可研只能写"预期分类与安排"
- 不要忽视双碳约束（即使非传统高耗能行业）
- 不要让环评批复时间与开工时间冲突
- 不要遗漏敏感目标识别（特别是学校 / 医院 / 文物）
