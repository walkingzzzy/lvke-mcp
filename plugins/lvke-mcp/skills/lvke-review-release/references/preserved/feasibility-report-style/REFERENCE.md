# Feasibility Report Style Review

Use this skill when polishing a document toward professional feasibility-study report style.

Focus on:

- Objective, evidence-based wording instead of marketing, advocacy, or unsupported optimism.
- Clear distinction between facts, assumptions, forecasts, risks, recommendations, and decisions pending approval.
- Appropriate level of detail for investment estimate, financing plan, benefit analysis, implementation path, and risk mitigation.
- Executive-summary clarity: decision-makers should see scope, basis, feasibility judgment, major risks, and next actions.

Return suggested rewrites only for problematic passages. Preserve technical meaning and flag places where evidence is needed before rewriting.
