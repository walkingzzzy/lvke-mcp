# 数字一致性核查（Numerics Cross-Check）

可研报告中的数字串通常分散在多个章节：第 3 章规模、第 4 章方案、第 5 章投资、第 6 章财务、附表 / 附图。**任何一处错误都会让评审人质疑全文严谨度**。本 skill 是审查中**最容易立刻发现问题**的一环。

## 何时使用

用户说："核对数字"、"数据一致吗"、"投资估算和正文对得上吗"、"产能和规模吻合吗"、"再读一遍数字"。

或者在做 `doc-review-compliance` / `doc-review-feasibility-report-style` 时发现数字异常，单独深入。

## 工作流

```
1. doc_read 取全文（或 context_view 取章节摘要）
2. 抽取所有关键数字 → 按维度分组
3. 比对组内一致性 → 标记冲突
4. doc_review 提交 issues（每条 issue = 一个冲突点 + 严重度）
```

## 关键数字维度（6 类）

### 1️⃣ 投资类

- **总投资**：1 章总论结论 / 5 章估算总表 / 6 章财评起算 / 摘要
- **建设投资 vs 流动资金**：5 章应有清晰拆分
- **资金来源**：自有资金 + 银行 + 其他 = 总投资（务必对账）
- **单位投资**：万元/吨、万元/平方米、万元/床位 ... 行业 baseline 比对

### 2️⃣ 规模 / 产能类

- **产能**：3 章测算 / 4 章方案 / 5 章估算依据 三处应同口径
- **设计规模 vs 实际负荷率**（如 80% 负荷）：6 章财评有时按负荷算
- **规模单位陷阱**：吨 / 万吨 / GWh / MW / 万件 —— 注意单位换算
- **峰值 vs 年均**：水务 / 能源类常用峰值，但运营按年均

### 3️⃣ 占地 / 建筑类

- **总占地**：4 章方案 / 用地预审文件
- **建筑面积**：地上 + 地下分别列示
- **绿地率 / 容积率 / 建筑密度** —— 三者关系不能矛盾

### 4️⃣ 人员 / 编制类

- **总人员**：4 章方案（运营组织）/ 5 章估算（人工费基础）/ 6 章财评（工资支出）
- **班次结构**：单班 / 两班 / 三班对运营成本影响大

### 5️⃣ 工期 / 进度类

- **建设期**：4 章方案 / 5 章估算（建设期利息）/ 6 章财评（贴现年数）
- **运营期**：6 章一致（通常 10-30 年）
- **总评价期** = 建设期 + 运营期

### 6️⃣ 财务关键指标

- **IRR / NPV / 回收期**：6 章正文 / 摘要 / 1 章结论
- **税前 / 税后 / 资本金 / 全投资** —— 类型必须明确
- **敏感性临界点** vs 基准方案 —— 数字关系应合逻辑

## 审查 SOP

### 步骤 1：扫描全文抽取

```
对每个章节做 doc_read（按 range="3"、"4"、"5"、"6" 分章读）
按 6 类维度建表格记录每个数字的出处
```

### 步骤 2：组内比对

对每一类的数字：

- 不同章节是否同口径？（如总投资必须三处一致）
- 单位是否统一？（吨 vs 万吨 vs t；MW vs kW）
- 加和是否成立？（建设投资 + 流动资金 = 总投资）
- 比率是否自洽？（资本金比例 + 借款比例 = 100%）

### 步骤 3：跨维度逻辑检查

- 单位投资 = 总投资 / 规模 → 应在行业合理区间
- 人均产值 = 收入 / 人员 → 行业 baseline 比对
- 投资强度（万元/亩）= 总投资 / 占地 → 与产业政策对照

### 步骤 4：产出 issues

每个冲突点写一条 issue：

```json
{
  "anchor": "5.2 投资估算总表 / 1.3 投资概算",
  "comment": "总投资两处不一致：5 章列 23,580 万元，1 章结论列 24,580 万元，相差 1,000 万元。建议核对建设期利息是否计入。",
  "severity": "high",
  "category": "数字一致性"
}
```

## 严重度判定

| 等级 | 标准 |
|---|---|
| **high** | 总投资 / IRR / 总规模 / 总占地 这种关键数字冲突 |
| **medium** | 子项数字（如某分项设备投资）冲突，但总数对 |
| **low** | 表达 / 描述差异（如"约 100 万元" vs "100 万元"），不影响理解 |
| **info** | 单位换算导致的细微差异（如四舍五入） |

## 边界

- **不臆造数字**：找不到的数字写 `[未找到]`，不要猜
- **不直接改正文**：发现问题写 issue，让用户决定怎么改
- **数字 ≠ 准确性**：本 skill 只检查"一致性"，不验证数字"合理性"（合理性见 `doc-review-compliance` 和 `financial-modeling-*`）

## 配套工具

- `doc_read`：按章节分块读
- `context_view`：获取章节列表与正文长度
- `doc_review`（with issues）：写入 issue_center
- `issue_update`：跟踪 issue 状态

## 常见陷阱

1. **单位翻译错**：原文写"500 kt"（千吨），表格写"500 万吨" —— 差 20 倍
2. **税前/税后混用**：1 章结论 IRR 12%（税前），6 章正文 IRR 10%（税后） —— 不是错但需标明
3. **静态/动态投资**：5 章列动态投资（含价差预备费 + 建设期利息），1 章列静态投资
4. **建设期利息归属**：放投资还是放融资费用，两种处理均可但全文要一致
