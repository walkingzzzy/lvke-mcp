# Compliance Review

Use this skill when reviewing a feasibility-study document for compliance.

Focus on:

- Claims that lack source evidence, dates, issuer names, or calculation basis.
- Commitments, guarantees, investment-return wording, or approval promises that exceed the document's authority.
- Missing statutory, policy, procurement, environmental, safety, financial, or data-source caveats.
- Conflicts between tables, appendices, citations, and body text.

Return findings with severity, location, issue, evidence needed, and recommended wording. Do not invent regulatory conclusions; mark uncertain items for human/legal review.
