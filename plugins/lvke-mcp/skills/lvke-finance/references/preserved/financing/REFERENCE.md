# 资金筹措建模 规范

第 5.5 节核心内容。资金筹措不仅是"列融资来源"，更要建模"资金到位时序 + 偿债能力 + 资本结构合理性"。

## 1. 资本结构 基本规则

### 资本金比例下限（国务院 2019 年规定）

| 行业 | 资本金最低比例 |
|---|---|
| 港口、沿海及内河航运 | 20% |
| 机场 | 25% |
| 一般铁路 | 25% |
| 城市轨道交通 | 25% |
| 公路 | 20% |
| 城市轨道交通 | 25% |
| 石油化工、煤炭、钢铁、有色 | 30% |
| 房地产开发 | 30%（保障房 25%） |
| 一般水利 | 20% |
| 其他工业 | 20% |
| 公共服务 | 30% |

⚠️ 不同地区、不同时期标准会调整。**起草前必须查最新政策**。

### 一般经验比例

| 项目类型 | 自有资金 | 银行贷款 | 政府 / 其他 |
|---|---|---|---|
| 一般工业 | 30%-40% | 50%-60% | 0%-10% |
| 公共项目 | 20%-30% | 30%-50% | 20%-50% |
| 房地产 | 30%-40% | 60%-70% | 0% |
| 农业项目 | 30%-50% | 30%-50% | 10%-30% |

## 2. 银行贷款建模

### 必要参数

```
- 贷款额度：万元
- 贷款期限：年（含建设期 + 还款期）
- 贷款利率：% / 年（固定 / 浮动 / LPR + bps）
- 偿还方式：等额本息 / 等额本金 / 利随本清 / 弹性还款
- 宽限期：年（建设期是否还本付息）
- 提款节奏：按月 / 按季 / 按工程进度
```

### 偿还方式公式

**等额本息**：
```
每期还款额 = P × r × (1+r)^n / ((1+r)^n - 1)
P = 贷款本金, r = 期利率, n = 期数
```

**等额本金**：
```
每期还本 = P / n
每期利息 = 剩余本金 × r
每期总额 = 等额本金 + 利息
```

**建设期利息处理**：
- 资本化（默认）：计入建设投资，运营期通过折旧体现
- 费用化：计入财务费用

⚠️ **资本化是行业惯例**。

### 偿债覆盖率（DSCR）

```
DSCR_t = (净利润 + 折旧 + 摊销 + 利息) / (年应还本息)
```

判断：
- DSCR < 1.0 → 当年无法还本付息 → 项目财务不可行
- DSCR ≥ 1.2 → 银行可接受
- DSCR ≥ 1.5 → 银行偏好

⚠️ 银行评审看 **悲观场景下的 DSCR**。

## 3. 政府配套资金

### 类型

- 财政直接投入（中央 / 省 / 市 / 县级专项资金）
- 贷款贴息
- 税收减免（按时间维度折现）
- 土地优惠（地价折让）
- 信用增级（担保 / 政府备债）

### 入账方式

| 类型 | 财务模型处理 |
|---|---|
| 直接投入 | 计入资金来源（非自有 / 非借贷） |
| 贷款贴息 | 计入财务费用减项 |
| 税收减免 | 现金流出减少 |
| 土地优惠 | 建设投资减少 |
| 担保 | 不直接入账，但降低贷款利率 |

⚠️ 政府配套资金**必须有明确文件依据**（政策文件 / 立项批复 / 申请意见）。

## 4. 复杂融资工具（可选）

### 项目债券 / 公司债

参数：发行规模、票面利率、期限、付息频率、增信

### 资产证券化（ABS）

参数：基础资产现金流、分层结构（优先 / 中间 / 劣后）

### 公募 REITs（基础设施）

参数：基础设施类型、收益率分配、扩募计划

### PPP（政府和社会资本合作）

参数：项目公司股权结构、可用性付费 / 使用者付费、运营期、回报机制

### 融资租赁

参数：租赁标的、租金、租赁期、买断条款

## 7. 数据一致性 5 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 资本金 + 借贷 + 其他 | = 总投资 |
| 2 | 资本金比例 | ≥ 行业最低 |
| 3 | 资金使用 | 与 4.8 进度一致 |
| 4 | DSCR | 计算口径明确，运营期最低 ≥ 1.2 |
| 5 | 利率 / 期限 | 与第 6 章财务费用一致 |

## 8. 常见陷阱

### 陷阱 1：资本金比例不合规
❌ 错：化工项目资本金 25%（要求 30%）
✅ 对：先查行业最低，再设结构

### 陷阱 2：政府配套无文件依据
❌ 错：写"政府专项资金 X 万"无政策文件
✅ 对：必须引用具体文件名 + 文号

### 陷阱 3：建设期利息漏算
❌ 错：贷款 1 亿 / 3 年建设期 / 5% 利率，但建设投资里没算入建设期利息
✅ 对：资本化处理，计入建设投资约 750 万

### 陷阱 4：DSCR 没分场景
❌ 错：只算基准 DSCR
✅ 对：基准 + 悲观至少两个场景

### 陷阱 5：贷款条件假设过分有利
❌ 错：利率 3%（明显低于市场）
✅ 对：按当前 LPR + 合理 bps（30-150 bps）

### 陷阱 6：资金使用与进度倒挂
❌ 错：M1-M3 需要 60% 资金，但贷款 M7 才到位
✅ 对：起步阶段用自有资金，后续大额用贷款

## 关键避免

- 不要在资本金不足时硬上 → 评审一定退回
- 不要让政府配套资金成为黑箱（无文件依据）
- 不要漏算建设期利息（巨额）
- 不要让 DSCR < 1.2 还推荐项目
