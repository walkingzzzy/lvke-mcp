# 运营定员编制

定人员与工资。承载工具：`planning_infer_labor_plan`。

## 由线路长度＋车站数＋班制推导

轨道运营定员的驱动量不是建筑面积，而是线路规模与班制：

| 岗位类别 | 工作量口径 | 班制 |
|---|---|---|
| 行车值班/信号楼 | 车站数 | 三班四运转 |
| 车站站务 | 车站数 × 每站岗位数 | 三班四运转 |
| 司机 | 上线列车数 × 单车日班次 | 三班四运转 |
| 车辆检修 | 配属列车数 | 常白班 + 夜间检修班 |
| 工务/供电/通号维修 | 线路长度（公里） | 常白班 + 夜间天窗 |
| 管理与调度 | 线网/线路固定编制 | 三班四运转（调度） |

`planning_infer_labor_plan` 的输入按岗位给：工作量、单人班次能力、班次数、覆盖因子、
自动化调整、人均年工资、福利率。人数由 ceil 推导，不填总人数。

## 覆盖因子

三班四运转的覆盖因子约 4.0（含轮休与年假替班），常白班约 1.15。用 1.0 会系统性
低估需轮班岗位的定员。

## 门禁

- 不用"单位面积人数"推轨道定员。地铁车站的建筑面积与所需站务人数无稳定关系。
- 自动化程度（全自动运行 GoA4 与人工驾驶 GoA2）显著改变司机与站务定员，
  必须以信号制式证据显式声明，不得默认。

## 反模式

- 用单位面积人数或行业默认总人数 → 与班制脱节
- 覆盖因子取 1.0 → 轮班岗位定员低估约 4 倍
