# 土地使用合规 规范

土地审批是项目开工前的必备硬约束。**土地手续不到位 → 项目不能开工**。本 skill 覆盖核心流程与要点。

## 1. 土地获取 5 种主要方式

| 方式 | 适用 | 周期 | 特点 |
|---|---|---|---|
| **划拨** | 公共项目（政府、军队、城市基础设施） | 短 | 免地价 |
| **出让（招拍挂）** | 商业开发、工业用地 | 中 | 公开竞价 |
| **协议出让** | 工业、公共设施部分 | 中 | 地价较低 |
| **租赁** | 中短期项目 | 短 | 不取得所有权 |
| **入股 / 联营** | 合资项目 | 长 | 土地作价入股 |

⚠️ 工业项目主流是 **出让 + 协议**。商业项目主流是 **招拍挂**。

## 2. 用地预审 流程

### 重要性

**项目立项前先做用地预审**。没预审就立项 → 后期发现地不合规 → 项目作废。

### 预审申请材料

- 项目可研报告
- 用地范围（含勘界图）
- 用地需求论证（人均 / 单位投资 / 单位产值用地指标）
- 是否占用永久基本农田 / 生态红线 / 林地说明
- 节地评估

### 审批层级

| 用地规模 / 类型 | 预审层级 |
|---|---|
| 一般工业建设用地 ≤ 35 公顷 | 县（市、区）自然资源局 |
| 一般工业建设用地 35-70 公顷 | 市自然资源局 |
| 一般工业建设用地 > 70 公顷 | 省自然资源厅 |
| 占用永久基本农田 | 国务院（极严） |
| 占用生态保护红线 | 国务院 |

## 3. 国土空间规划符合性

### 三调与一张图

- **第三次全国国土调查**（2018-2020 已完成）确定的地类是基础
- **国土空间规划"一张图"**（2020 年起逐级落地）
- 项目用地必须与规划"一张图"地类相符

### 用地类型 与 适用项目

| 规划地类 | 适用项目 |
|---|---|
| 工业用地 | 工业项目 |
| 仓储用地 | 物流仓储 |
| 公用设施用地 | 水、电、燃气、热力等市政 |
| 教育科研用地 | 学校 / 院所 |
| 医卫用地 | 医院 |
| 文化用地 | 文化场馆 |
| 商服用地 | 商业 / 服务业 |
| 居住用地 | 房地产 |
| 物流仓储 | 物流园 |
| 交通运输 | 道路 / 铁路 / 港口 / 机场 |

⚠️ 工业项目不能用商服用地，**地类错配是常见违规**。

## 4. 占补平衡 / 增减挂钩

### 占补平衡

占用耕地 → 必须开垦 **数量相等、质量不低于** 的耕地（"占一补一、占优补优"）。

### 增减挂钩

通过拆旧 / 复垦 → 释放建设用地指标 → 用于其他项目。

⚠️ 项目占用耕地必须有"占补平衡方案"，否则报告写"占用 X 亩耕地"无后文是问题。

## 5. 永久基本农田

### 定义

按法律划定的、严格保护、未经国务院批准不能占用的耕地。

### 占用程序

1. 县级人民政府申请
2. 省级人民政府审核
3. 国务院批准
4. 补划等量等质永久基本农田

⚠️ 普通工业项目几乎不可能占用永久基本农田，**项目选址必须避让**。

## 6. 节地评估

### 适用情形

- 投资 ≥ 50 亿元
- 占地 ≥ 100 公顷
- 重大基础设施项目

### 评估要点

- 人均用地（≤ 行业标准）
- 单位投资用地（≤ 行业标准）
- 容积率（≥ 行业最低）
- 建筑系数（≥ 行业最低）

## 7. 报告写法

```markdown
### 4.1.Y 用地合规分析

**项目用地规模**：占地 X 公顷（合 XX 亩）

**用地类型**：根据《XX 市国土空间规划（2021-2035）》"一张图"，
项目用地位于 **XX 工业园区**，规划地类为 **工业用地**，与项目类型相符。

**用地获取方式**：拟通过 **协议出让 / 招拍挂** 方式获取。

**用地预审情况**：
- 应申报预审层级：市自然资源局（占地 XX 公顷 < 35 公顷）
- 预审时间安排：M2-M3
- 预审与立项关系：立项前完成

**占用耕地情况**：
- 项目用地中耕地：X 公顷
- 永久基本农田：**0 公顷**（已避让）
- 占补平衡方案：拟通过 **XX 县 XX 镇 XX 项目** 实现等量等质补充

**生态红线 / 林地 / 湿地情况**：
- 生态保护红线：未占用
- 林地：占用 X 公顷（已申请林地审批）
- 湿地：未涉及

**节地评估情况**：
- 人均用地：X m²/人（≤ 行业标准 X m²/人）
- 单位投资用地：X m²/万元（≤ 行业标准 X）
- 容积率：X（≥ 行业最低 X）
```

## 8. 数据一致性 4 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 占地面积 | 4.1 / 4.6 / 5.2 / 8.3 一致 |
| 2 | 规划地类 | 与"一张图"地类相符 |
| 3 | 用地预审进度 | 立项 / 开工前完成 |
| 4 | 土地费用 | 5.2 工程建设其他费 "土地使用费" 体现 |

## 9. 常见缺陷

1. **规划地类不符** —— 工业项目落在商服地块
2. **占用永久基本农田未识别** —— 选址时未对照基本农田红线图
3. **占补平衡缺方案** —— 占用 X 亩耕地无补偿安排
4. **用地预审滞后** —— 立项后才申请，导致后期发现地不合规
5. **节地评估缺项** —— 占地 > 100 公顷未做节地评估
6. **土地费用估算太低** —— 协议出让仍要付不低于地价基准

## 关键避免

- 不要在选址前没查"一张图"地类
- 不要在占用耕地时不做占补平衡
- 不要把"用地预审"放在立项之后
- 不要忽略"林地审批"（很多工业项目需要）
- 不要把农田 / 草地按建设用地估土地成本
