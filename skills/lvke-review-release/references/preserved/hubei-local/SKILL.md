# 湖北省地方政策 合规规范

湖北省项目除遵循国家级政策外，还有大量省级和地方级专项政策。**忽略地方政策 → 错过红利或踩雷被退回**。本 skill 覆盖湖北省核心要点。

## 1. 长江经济带 / 长江保护

### 核心政策

- 《中华人民共和国长江保护法》（2021 年 3 月施行）
- 《长江经济带发展规划纲要》
- 湖北省"共抓大保护、不搞大开发"实施意见
- 长江岸线 1km / 3km 管控红线

### 主要约束

**长江干流岸线 1km 范围内**：
- 禁止新建、扩建化工园区和化工项目
- 禁止新设排污口（除饮用水水源外）
- 严格限制重污染、高耗能项目

**长江干流岸线 1km-3km 范围内**：
- 严格控制规划布局
- 禁止新建有重大风险的设施

⚠️ 湖北作为长江流经里程最长省份，**任何沿江项目必须做长江保护合规分析**。

### 报告写法

```markdown
**长江保护合规**：
- 项目距长江干流距离：**XX km**（位于 1km / 3km / 3km 外）
- 长江保护法适用要求：[X]
- 项目类型与长江保护红线相符性：[符合 / 需调整]
- 长江排污口管控：[本项目无 / 有排污口，按 XX 标准]
```

## 2. 武汉自贸片区 / 综合保税区

### 主要片区

- **中国（湖北）自贸试验区武汉片区**（光谷东湖高新区为核心）
- **中国（湖北）自贸试验区襄阳片区**
- **中国（湖北）自贸试验区宜昌片区**
- 武汉新港综合保税区
- 武汉光谷综合保税区
- 黄石综合保税区

### 自贸片区 优势

- 简化外汇 / 跨境结算
- 部分外资准入放宽
- "证照分离"改革
- 通关便利化（属地申报）
- 部分税收 / 财政补贴优惠

### 报告写法

```markdown
**项目所在片区**：
- 项目地址：武汉光谷东湖高新区 / 自贸试验区武汉片区核心区
- 适用政策：
  - 中国（湖北）自贸试验区总体方案
  - 武汉东湖新技术开发区企业上市奖励办法
  - 光谷"金种子"高成长企业培育计划
```

## 3. 武汉光谷 / 长江中游城市群

### 武汉东湖新技术开发区（光谷）

光谷重点扶持产业：
- 集成电路
- 新型显示
- 光通信
- 生物医药 / 大健康
- 智能制造
- 数字经济

光谷专项政策：
- 高新技术企业认定加速通道
- 研发投入加计扣除
- "3551 光谷人才计划"
- 上市企业奖励

### 长江中游城市群

- 武汉、长沙、南昌为核心
- 武汉都市圈（武汉 + 鄂州 + 黄冈 + 黄石 + 咸宁 + 孝感 + 仙桃 + 天门 + 潜江）

跨城市群政策：
- 产业转移协同
- 基础设施互联互通
- 公共服务一体化

20 大重点产业链（百亿级）：[省发改委发布的具体目录]

### 招商优惠（典型）

- 用地：协议出让地价优惠（不低于工业用地最低价）
- 财政：投资奖励 / 一次性补贴 / 持续性奖励
- 人才：高层次人才补贴
- 金融：贷款贴息 / 风投跟投

⚠️ 招商优惠**必须有具体文件依据**，写"地方政府承诺"无文件依据不严谨。

## 5. 湖北农业 / 乡村振兴

### 重点政策

- 国家粮食安全产业带（湖北作为粮食主产省）
- 乡村振兴战略
- 现代农业产业园 / 农业产业强镇 / 一村一品
- 农业农村部 + 湖北省财政厅扶持项目

### 适用项目

- 现代农业园区
- 农业加工
- 数字乡村 / 智慧农业
- 高标准农田建设

## 6. 湖北生态保护 特殊约束

### 长江生态保护

详见第 1 节。

### 神农架 / 大别山 / 武陵山 / 幕阜山等山区

- 生态保护红线密集
- 文化与生物多样性热点
- 项目落地受严格限制

### 长江水系湿地保护

- 武汉湿地（沉湖、涨渡湖、上涉湖等）
- 洪湖湿地
- 受 Ramsar 公约保护

### 城市生态红线

武汉等城市划定的"生态红线"：
- 不得用于建设
- 不得改变原生地类

**适用地方优惠政策**：

|---|---|---|---|

## 8. 数据一致性 4 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 项目所在地 | 与 4.1 选址一致 |
| 2 | 产业类别 | 与"51020" / 国家产业结构调整指导目录对照 |
| 3 | 地方优惠 | 有文件依据，金额合理 |
| 4 | 生态合规 | 长江 / 湿地 / 红线核查 |

## 9. 常见缺陷

1. **未引用长江保护法约束** —— 沿江项目忽略 1km / 3km 红线
2. **地方优惠无文件依据** —— 招商承诺写入报告但无政策文件
3. **未识别"51020"产业链匹配** —— 错过重点产业优惠
4. **未识别长江中游 / 武汉都市圈协同** —— 跨市项目忽略协同政策
5. **湿地 / 红线占用未识别** —— 武汉等城市生态红线密集
6. **政策时效错** —— 引用 2018 / 2020 已废止文件
