# 立项审批 合规规范

立项审批是项目"获得身份证"。**审批方式选错 → 长期挂在审批阶段无法开工**。

## 1. 三种立项制度

### A. 审批制

适用：**政府投资项目**（财政性资金或政府融资平台）

文件：可研报告 → **审批批复（"批复书"）**

需要的支持文件（典型）：
- 立项申请报告
- 可行性研究报告
- 用地预审意见
- 环评批复
- 节能审查意见
- 选址意见书
- 其他专项审批

⚠️ 政府投资项目要先审批后开工。**不能边干边批**。

### B. 核准制

适用：**企业投资关系国家安全、生态、重大公共利益的项目**

文件：项目申请报告 → **核准批文**

核准目录（《政府核准的投资项目目录》最新版，目前是 2016 版 + 多次修订）：
- 农业水利（大型水库、调水、跨流域）
- 能源（核电、煤层气、大型水电、风电海上）
- 交通运输（铁路、公路、机场、港口的特定类型）
- 信息（基础电信、特定外资）
- 原材料（特定钢铁、铝、石化、化工、稀土）
- 机械制造（大型造船等）
- 高技术（特定外资）
- 城建（人防、特定开发）
- 社会事业（特定教育、医疗、影视、文化遗产保护）

### C. 备案制

适用：**企业投资不在核准目录内的所有项目**

文件：项目基本情况 → **备案表 / 备案证明**

⚠️ **绝大多数企业投资工业 / 商业 / 服务业项目走备案**。

## 2. 审批层级

### 政府投资项目

| 资金来源 | 审批层级 |
|---|---|
| 中央财政 / 中央补助 | 国家发改委 |
| 省级财政 | 省发改委 |
| 市级财政 | 市发改委 |
| 县级财政 | 县发改委 |

### 企业投资核准

| 项目类型 | 核准层级 |
|---|---|
| 国家发改委权限 | 国家发改委 |
| 省发改委权限 | 省发改委 |
| 市发改委权限 | 市发改委 |

⚠️ 不同地区不同行业的权限不同。**起草前查最新权限清单**。

### 企业投资备案

| 项目地点 | 备案层级 |
|---|---|
| 项目所在地 | 县 / 市发改委 |
| 大型项目 | 上一级发改委 |

## 3. 资本金比例 合规

详见 `financial-modeling-financing` 第 1 节。

立项审批环节会**审核资本金比例是否符合行业最低**：

- 钢铁 / 化工 / 水泥 等：30%
- 房地产开发：30%（保障房 25%）
- 港口 / 沿海航运：20%
- 一般工业：20%
- 公共服务：30%

**资本金不足 → 立项不通过**。

## 4. 企业投资负面清单

### 全国负面清单（2024 版）

明令禁止的领域：
- 国家不允许外资 / 民营资本进入的领域（如部分军工、稀土深加工等）
- 落后产能（按行业产业结构调整指导目录"淘汰类"）
- 重复建设产能严重过剩的领域（按工信部公告）

### 限制类领域

- 需要符合特定条件（如能耗强度、规模限值）
- 通常需要核准
- 优惠政策不适用

⚠️ 起草前必须查项目所属行业在产业结构调整指导目录中的分类（鼓励 / 限制 / 淘汰）。

## 5. 审批文件 准备清单

### 政府投资项目（审批制）

立项前 / 立项后必备：
- 立项申请报告
- 可研报告（含本工作台输出）
- 选址意见书
- 用地预审与规划选址意见书
- 环境影响评价批复
- 节能审查意见
- 水土保持审批
- 行业特定审批（如水利、海洋、文物等）

### 核准制项目

- 项目申请报告（PSR）
- 城乡规划行政主管部门出具的城乡规划意见
- 国土资源行政主管部门出具的预审意见
- 环保行政主管部门出具的预审意见
- 节能审查意见
- 行业特定要求

### 备案制项目

- 项目基本情况表
- 投资协议（如涉及多方）
- 其他依规要求

## 6. 报告写法（第 9 章 / 第 8.2 节）

```markdown
### 9.4.X 立项审批安排

**审批制度选择**：

本项目为 **企业投资项目**，根据《政府核准的投资项目目录（2016 年本）》及历次修订，
项目所属行业 **XXX** ：
- [ ] 列入国家核准目录 → 适用 **核准制**
- [x] 未列入核准目录 → 适用 **备案制**

**审批层级**：
- 备案机关：**XXX 市发改委 / XXX 县发改委**

**资本金比例**：
- 项目资本金占总投资 **30%**，符合 **XXX 行业最低 20%** 要求

**审批进度安排**：

| 序号 | 审批事项 | 主管部门 | 计划完成时间 |
|---|---|---|---|
| 1 | 选址意见 | 自然资源局 | M1 |
| 2 | 用地预审 | 自然资源局 | M2 |
| 3 | 节能审查 / 报告 | 发改委 / 节能机构 | M3 |
| 4 | 环境影响评价 | 生态环境局 | M3-M6 |
| 5 | 项目备案（核准） | 发改委 | M6 |
| 6 | 用地手续 | 自然资源局 | M7 |
| 7 | 规划许可 | 自然资源局 | M8 |
| 8 | 施工许可 | 住建局 | M9 |
| 9 | 开工 | - | M9 |

**负面清单核查**：
- 项目所属行业：**XXX**
- 是否列入"淘汰类 / 限制类"：**否**
- 是否列入鼓励类：**是 / 否**
- 优惠政策预期：[列具体优惠]
```

## 7. 数据一致性 5 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 审批制度选择 | 与行业目录对应 |
| 2 | 资本金比例 | 5.5 / 6 / 9 一致 |
| 3 | 审批进度 | 与 4.8 / 9.4 一致 |
| 4 | 各专项审批批复时间 | 在开工时间之前 |
| 5 | 负面清单 | 行业 / 地区双核查 |

## 8. 常见缺陷

1. **审批制度选错** —— 政府投资项目按备案制走（流程不合规）
2. **资本金不足** —— 化工项目用 25% 资本金（要求 30%）
3. **审批进度倒挂** —— 开工时间早于环评批复时间
4. **未识别负面清单** —— 项目实际在"淘汰类"未识别
5. **核准与备案混用** —— 核准项目走备案流程
6. **审批层级判断错** —— 大型项目应报国家发改委却报市发改委

## 关键避免

- 不要把政府投资项目按备案制处理
- 不要在资本金比例上"打擦边球"
- 不要让开工时间早于关键专项审批
- 不要忽略产业结构调整指导目录核查
