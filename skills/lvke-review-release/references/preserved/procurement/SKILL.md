# 招投标 / 政府采购 合规规范

第 4 章 / 第 8 章涉及招投标安排。**漏列依法必招项目 / 招标方式不合规 → 监管退回**。

## 1. 依法必须招标 范围

### 工程招标范围（《招标投标法》及实施条例）

必须招标的工程：
- 使用 **国有资金 ≥ 50% 或居控股 / 主导地位** 的项目
- 使用 **国际组织 / 外国政府贷款 / 援助资金** 的项目
- 大型基础设施 / 公用事业项目（涉及社会公共利益）

### 必招规模标准（住建部 2018 第 16 号令）

工程招标必须达到的规模标准：
- **施工单项合同估算价 ≥ 400 万元**
- **重要设备 / 材料采购合同 ≥ 200 万元**
- **勘察 / 设计 / 监理 等服务合同 ≥ 100 万元**
- **同一项目分项目合计 ≥ 上述限额**

⚠️ 不达限额可不招标但建议比选。

## 2. 招标方式 4 种

| 方式 | 适用 | 周期 | 公开度 |
|---|---|---|---|
| **公开招标** | 大部分工程 / 货物 | 长（≥ 30 天） | 全社会公开 |
| **邀请招标** | 特殊设备 / 专业服务（≥ 3 家） | 中 | 邀请部分 |
| **竞争性谈判** | 紧急 / 不确定方案 | 短 | 邀请部分 |
| **单一来源** | 唯一供应商 / 紧急 | 短 | 不公开 |

### 何时可邀请招标

- 工程项目：使用国有资金的项目且具有以下情形之一
  - 项目技术复杂、有特殊要求或者受自然环境限制，只有少量潜在投标人可供选择
  - 项目涉及国家安全、国家秘密、抢险救灾
  - 项目处于战略位置不适合公开招标

### 何时可单一来源

- 必须经主管部门批准
- 必须公示理由

## 3. 政府采购特殊规定

### 政府采购法适用范围

- 各级国家机关、事业单位、团体组织
- 用财政资金采购货物、工程、服务

### 政府采购方式（《政府采购法》及实施条例）

| 方式 | 适用 |
|---|---|
| 公开招标 | 主要方式 |
| 邀请招标 | 货物 / 服务 ≥ 邀请招标限额 |
| 竞争性谈判 | 特殊情形 |
| 单一来源 | 唯一供应商 / 行政 |
| 询价 | 货物 < 200 万 |
| 框架协议 | 反复需要的标准化货物 |

### 集中采购目录

各级财政部门发布**集中采购目录**。在目录内的：
- 必须委托集中采购机构集中采购
- 或经财政部门批准分散采购

## 4. 招标计划编制

### 必含内容

| 招标包 | 招标方式 | 招标人 | 招标范围 | 估算金额 | 招标时间 | 中标合同时间 |
|---|---|---|---|---|---|---|
| 1. 主体工程施工 | 公开招标 | 项目业主 | 全部土建 / 安装 | X 万元 | M5 | M7 |
| 2. 主要设备 | 公开招标 | 项目业主 | A/B/C 设备 | X 万元 | M4 | M6 |
| 3. 监理服务 | 邀请招标 | 项目业主 | 全程监理 | X 万元 | M3 | M5 |
| 4. 勘察设计 | 公开招标 | 项目业主 | 初步设计 / 施工图 | X 万元 | M1 | M3 |

⚠️ 招标计划要包含**所有达到必招限额**的标段，不能遗漏。

### 招标周期 标准

| 阶段 | 周期 |
|---|---|
| 资格审查 | 15-30 天 |
| 招标文件编制 | 15-30 天 |
| 发布公告至投标截止 | ≥ 30 天（公开） |
| 评标 | 1-5 天 |
| 公示中标人 | 3 天 |
| 签订合同 | 30 天内 |
| **合计公开招标** | **3-4 个月** |

⚠️ 项目进度表要预留招标时间，**不能压缩到 1 个月**。

## 5. 合同管理

### 合同管理要求

- 标准合同范本（建设工程施工合同 GF-2017-0201 等）
- 合同备案（住建部门 / 财政部门）
- 履约保证金（项目业主收取，一般 10%）
- 工程预付款 / 进度款 / 竣工结算
- 工程验收 + 决算审计

| 主要设备采购 | XXX 万元 | 公开招标 | ≥ 200 万 |

## 7. 常见缺陷

1. **遗漏依法必招项目** —— 监理 / 设计 漏招 → 监管退回
2. **达到限额却写"询价"** —— 把 500 万设备写询价方式
3. **招标周期挤压** —— 预留 1 个月就能完成公开招标（不可能）
4. **政府采购走招投标程序** —— 用国有资金未走政府采购集采流程
5. **单一来源未公示** —— 直接说"只能由 X 供应商提供"
6. **合同方式不规范** —— 没用住建部范本

## 关键避免

- 不要漏列必招项目（特别是监理 / 勘察设计）
- 不要把招标周期压缩到 1 个月以内
- 不要在用国有资金的项目用"邀请招标"理由不充分
- 不要忽略政府采购集中采购目录约束
