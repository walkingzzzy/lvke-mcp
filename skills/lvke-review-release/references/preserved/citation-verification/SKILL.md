# 引用核查（Citation Verification）

可研报告靠"引用"建立可信度：引用国家政策、统计数据、行业标准、地方文件、国际指南。**任何一条假引用或过期引用都会让评审专家立即降低对全文的信任度**。本 skill 是"防造假"的第一道关。

## 何时使用

- 用户说："核实出处"、"查一下这个文号是真的吗"、"这些政策还有效吗"、"统计数字来源"
- 在做 `doc-review-compliance` / `policy-compliance-*` 时遇到具体引用
- 在做 `report-drafting-chapter-2-background` / `chapter-7-risk` 后做最后一遍引用复核

## 工作流

```
1. doc_read 或 context_view 抓全文
2. 扫描引用 → 按类型分组
3. 逐条核查（如有 mcp-policy-search / mcp-statistics-cn，优先调用）
4. 标记三态：✓ 真实有效 / ⚠️ 真实但已过期 / ❌ 未找到或异常
5. doc_review 写入 issue
```

## 引用类型清单

### 1️⃣ 政策文件

格式特征：`国务院 [2024] X 号 / 发改委 X〔YYYY〕XXXX 号 / 鄂政发 [YYYY] XX 号`

核查项：
- **真实性**：文号在官方政府网站存在
- **时效性**：是否被废止 / 失效 / 替代
- **适用性**：是否真适用于本项目类型 / 地区
- **完整性**：引用条款编号是否正确（如"第 X 条"）

工具优先级：
1. mcp-policy-search（如配置）
2. web_search "[文号] site:gov.cn"
3. terminal `curl` 检索

### 2️⃣ 统计数据

格式特征：「2023 年湖北 GDP 达 X.X 万亿元，同比增长 Y%」

核查项：
- **来源**：国家统计局 / 省统计局 / 行业协会 / 智库
- **时效**：是否使用最新一期数据（一般不超过 18 个月）
- **口径**：现价 / 不变价 / 同口径 / 调整后
- **指标定义**：避免"GDP" vs "人均 GDP" vs "工业增加值" 混用

工具优先级：
1. mcp-statistics-cn（如配置）
2. web_search "[年份] [指标] 国家统计局"

### 3️⃣ 行业标准 / 国家标准

格式特征：`GB/T XXXXX-YYYY / DB42 XXXX-YYYY（湖北地标）/ JGJ XX-YYYY（行业）`

核查项：
- **现行版本**：是否最新版（注意 YYYY）
- **是否被取代**：原标准是否已废止
- **强制性 vs 推荐性**：GB 强制 vs GB/T 推荐
- **适用范围**：实际是否覆盖本项目

### 4️⃣ 学术 / 行业研报

格式特征：「根据 XX 咨询研究院 / 万得资讯 / Wind / 中电联...」

核查项：
- **机构权威性**：是否业内公认（不是无名机构）
- **数据来源**：研报是否注明二手来源
- **发布时间**：报告新鲜度
- **付费墙**：评审专家是否能 access

### 5️⃣ 案例 / 类比项目

格式特征：「参考 XX 项目（地点、年份）..."」

核查项：
- **真实存在**：项目真实可查
- **可比性**：规模 / 行业 / 地理是否真可比
- **数据准确**：投资额 / IRR 等参数是否准确

## 审查 SOP

### 步骤 1：抽取所有引用

```
doc_read 全文，做 grep：
- 正则：\d+[年〔[][\d-]+\d+[]〕号]
- 关键词："根据"、"按照"、"参照"、"来源："、"国家统计局"、"GB"、"JGJ"...
按出现位置 + 引用类型分组
```

### 步骤 2：核查与标记

每条引用标三态：

| 标记 | 含义 | 处理 |
|---|---|---|
| ✓ | 真实有效 | 通过 |
| ⚠️ | 真实但已被替代 / 时效不佳 | 写 medium issue 建议更新 |
| ❌ | 完全找不到 / 文号格式错误 | 写 high issue，建议人工复核 |

### 步骤 3：产出 issues

```json
{
  "anchor": "2.3 政策背景 / 第一段",
  "comment": "引用「发改投资〔2018〕23 号」与本项目类型不符 —— 该文是 PPP 规范文件，本项目为企业自有投资。建议替换为「企业投资项目核准和备案管理条例（2017 修订）」。",
  "severity": "high",
  "category": "引用核查"
}
```

## 严重度判定

| 等级 | 标准 |
|---|---|
| **high** | 文号假 / 标准已废止 / 引用根本不存在 |
| **medium** | 引用真但时效不佳（旧版数据 / 替代标准已发布） |
| **low** | 引用真，但表述不精准（如缺年份 / 缺文号） |
| **info** | 格式问题（如缺顿号 / 编号格式） |

## 边界

- **不杜撰核查结论**：如果工具拒绝 / 网络失败，写 `[需人工复核]` 而非"我认为没问题"
- **不直接改文号**：发现错误 → 写 issue，由用户决定如何修订（怕错改成另一个错文号）
- **政策更新风险**：核查"现行有效"基于核查当日；agent 不保证之后不被废止 → 建议在终稿前最后一次核查

## 配套工具

- `doc_read` / `context_view`：抓引用
- `mcp_policy_search_*`（如配置）：政策检索（首选）
- `mcp_statistics_cn_*`（如配置）：统计核查
- `web_search`：通用核查（兜底）
- `doc_review` / `issue_update`：issue 流转

## 常见陷阱

1. **文号格式陷阱**：`国发〔2024〕X 号` 用全角 `〔〕`，不是 `[]`；agent 容易看成假文号
2. **统计口径陷阱**：「2024 年 GDP 增长 5%」—— 是同比？环比？折年率？
3. **过期文件陷阱**：「环境影响评价公众参与办法（2006）」已被 2018 年版替代
4. **地方变体陷阱**：湖北、武汉、东湖高新各有不同等级地方文件，引用错层级常见

## 配合其他 skill

- 先 `doc-review-citation-verification` 核引用真实性
- 再 `policy-compliance-*` 核引用条款是否适用本项目
- 最后 `doc-review-compliance` 综合判断是否还有更高层政策缺引

三者次序不能乱。
