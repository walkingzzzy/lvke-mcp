# Consistency Review

Use this skill when checking a feasibility-study document for internal contradictions.

Focus on:

- Numeric consistency across summary, body, tables, appendices, and formulas.
- Timeline consistency across construction, procurement, approval, financing, and operation phases.
- Entity names, project scope, locations, capacities, units, assumptions, and boundary conditions.
- Whether conclusions are supported by earlier analysis and whether risks are reflected in mitigation plans.

Return each inconsistency with both conflicting locations, the impact, and the proposed reconciliation path. Do not silently choose one value when the source of truth is unclear.
