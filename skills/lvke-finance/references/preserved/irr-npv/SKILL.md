# IRR / NPV 计算规范

IRR 和 NPV 是项目财务评价的两个核心指标。**算错或口径不一致就是评审专家最容易抓的硬伤**。本 skill 给出可重算的标准方法。

## 1. 基本概念

### NPV（净现值）

```
NPV = Σ (CF_t / (1 + r)^t)  for t = 0 to n
```

- `CF_t`: 第 t 年的净现金流
- `r`: 折现率（行业基准收益率 / 企业要求收益率）
- `t`: 年份（建设期算第 0 年起）
- `n`: 总计算期

判定：NPV > 0 → 财务可行
判定：NPV < 0 → 财务不可行

### IRR（内部收益率）

```
NPV(IRR) = 0
```

即让 NPV = 0 的折现率。

判定：IRR > 行业基准 → 财务可行
判定：IRR < 行业基准 → 财务不可行

### 静态投资回收期

```
累计净现金流 = 0 的年份（不考虑折现）
```

### 动态投资回收期

```
累计折现净现金流 = 0 的年份（考虑折现）
```

## 2. 两种 IRR / NPV：项目 vs 资本金

### 项目 IRR / NPV

视角：所有投资人合计

```
CF_t（项目）=
  + 营业收入
  - 经营成本（不含利息）
  - 销售税金及附加
  - 所得税（按"项目全投资"假设计算）
  - 建设投资
  - 流动资金
  + 流动资金回收（末年）
  + 残值（末年）
```

⚠️ **项目 IRR 计算时所得税要按"假设没有借贷利息" 算**，否则会重复扣减。

### 资本金 IRR / NPV

视角：股东 / 出资人

```
CF_t（资本金）=
  + 项目 CF_t
  - 借贷本金（建设期借入年为流入）
  - 借贷本金偿还（运营期）
  - 借贷利息
  + 借贷利息抵税
```

⚠️ **资本金 IRR 反映的是股东收益**，杠杆越高越敏感。

## 3. 折现率的选择

| 项目类型 | 折现率参考 |
|---|---|
| 一般工业（税后） | 8% |
| 公共基础设施（税前） | 6-8% |
| 房地产 | 10-12% |
| 国家鼓励项目 | 6% |
| PPP 项目 | 看 PA 协议约定 |
| 国家发改委评审基准 | 当前 6-10%（按行业差异） |

⚠️ 选择折现率必须写明依据，**不能拍头**。

## 4. 计算可重算性 8 项 checklist

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 计算期 | 建设期 + 运营期 = 总计算期 一致 |
| 2 | 折现率 | 明确标出（如 8%，且写明依据） |
| 3 | 现金流公式 | 明确列出 CF_t 的构成 |
| 4 | 项目 IRR 所得税口径 | 按"假设全投资"算 |
| 5 | 资本金 IRR 杠杆 | 借贷条件（额度 / 期限 / 利率）明确 |
| 6 | 残值与流动资金回收 | 末年纳入正值 |
| 7 | 折旧不算现金流出 | 计算时加回（已是会计扣除项） |
| 8 | 单位 | 万元 / 亿元 全表统一 |

## 5. 现金流表标准模板

```
项目计算期    | 0  | 1  | 2  | 3  | ... | n
---|---|---|---|---|---|---
建设投资     | -X |     |     |     |     |
流动资金     |     | -X  |     |     |     | +X (末年回收)
营业收入     |     | X   | X   | X   | ... | X
经营成本     |     | -X  | -X  | -X  | ... | -X
销售税金附加 |     | -X  | -X  | -X  | ... | -X
所得税       |     | -X  | -X  | -X  | ... | -X
残值回收     |     |     |     |     |     | +X
---|---|---|---|---|---|---
净现金流 CF  | -X | X   | X   | X   | ... | X+X+X
累计净现金流 | -X | -X  | -X  | X   | ... | X
折现现金流   | -X | X/1.08 | X/1.08² | X/1.08³ | ... | X/1.08^n
NPV          | Σ
IRR          | f(CF) = 0
```

## 6. 常见陷阱

### 陷阱 1：把折旧算成现金流出
❌ 错：CF = 收入 - 经营成本 - 折旧 - 税
✅ 对：CF = 收入 - 经营成本 - 税（折旧不是现金流，已通过税前抵扣体现）

### 陷阱 2：项目 IRR 算入借贷利息
❌ 错：项目 IRR 现金流减去借贷利息
✅ 对：项目 IRR 假设全是自有资金（所得税按假设全投资算）

### 陷阱 3：末年没回收流动资金 / 残值
❌ 错：末年只有正常运营现金流
✅ 对：末年要加上 流动资金回收 + 固定资产残值

### 陷阱 4：建设期超过 1 年但只放一个支出节点
❌ 错：3 年建设期投资全放第 0 年
✅ 对：按建设计划逐年分配（如 30% / 50% / 20%）

### 陷阱 5：折现率与基准收益率混用
❌ 错：折现率 = 10%，行业基准 = 8%，结论"IRR 12% > 10% 可行"
✅ 对：判断 IRR 12% > 行业基准 8% → 可行

### 陷阱 6：多解 IRR 没识别
❌ 错：现金流符号变化 ≥ 2 次时仍报"IRR = 12%"
✅ 对：识别可能有多个 IRR 解 → 用 NPV 判断或修正 IRR (MIRR)

### 陷阱 7：单位混用
❌ 错：表内 万元 / 亿元 / 元 混用
✅ 对：全表统一（推荐 万元）

## 7. 配套工具

- `finance.tools` MCP 服务：可重算 IRR / NPV / 投资回收期
- Excel：内置 `=IRR(...)` `=NPV(rate, range)` 函数
- Python：`numpy.irr(cashflows)`、`numpy.npv(rate, cashflows)`
- 国家发改委的"经济评价软件"

⚠️ 任何工具的结果都要附**输入与公式**，确保可复核。

## 8. 报告中的写法

```markdown
**计算依据**：
- 计算期：15 年（建设期 3 年 + 运营期 12 年）
- 折现率：8%（按行业基准收益率）
- 建设投资：X 万元，按 30/50/20 分布
- 营业收入：达产年 X 万元，达产率 80%/90%/100%（前 3 年爬坡）
- 经营成本：见 6.3 节

**计算结果**：
- 项目 IRR = 12.5%（> 行业基准 8%，可行）
- 项目 NPV = X 万元（> 0，可行）
- 项目静态投资回收期 = X 年
- 项目动态投资回收期 = X 年
- 资本金 IRR = 18.3%（> 股东要求 15%，可行）
- 资本金 NPV = X 万元
```

## 关键避免

- 不要只报 IRR / NPV 数值，必须附完整现金流表
- 不要用 IRR 单独决策（与 NPV 矛盾时以 NPV 为准）
- 不要让 IRR 高过 30% 还不警觉（除非新兴行业，一般要复核数据）
- 不要把"基准收益率"和"贷款利率"混用
