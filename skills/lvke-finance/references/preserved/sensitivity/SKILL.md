# 单因素敏感性分析 规范

第 6.6 节核心内容。敏感性分析回答的问题是："**如果某个关键假设错了，IRR / NPV 会怎么变？**"。**不做敏感性 → 财务可行性结论不被认可**。

## 1. 基本方法

### 单因素法

固定其他所有变量，只让 **一个因子** 上下浮动 ±10% / ±20%，看 IRR / NPV 怎么变。

### 双因素法（可选）

同时让两个因子变动，看组合影响（用 IRR 等值线图呈现）。

### 概率分析 / 蒙特卡洛（可选）

为所有因子分配概率分布，模拟数千次得到 IRR / NPV 概率分布。

⚠️ **大部分项目用单因素法足够**。蒙特卡洛只在大型 / 政府重大项目要求。

## 2. 必含 5 个因子

| 因子 | 浮动区间 | 含义 |
|---|---|---|
| 销售收入 / 价格 | ±10%、±20% | 市场价格风险 |
| 经营成本 | ±10%、±20% | 成本风险 |
| 建设投资 | ±10%、±20% | 投资超支风险 |
| 产能利用率 / 销量 | ±10%、±20% | 需求风险 |
| 销售税金 / 税率 | ±10%、±20% | 政策风险 |

可选额外因子：
- 工期延长
- 折现率本身
- 汇率（涉外项目）
- 原材料价格

⚠️ **最少 5 个**。少于 5 个会被评审打回。

### B. 敏感性曲线图

横轴：因子变化 ±%
纵轴：IRR %
五条线（5 个因子）

### C. 敏感系数表

```
敏感系数 = |ΔIRR / ΔX|
```

按敏感系数大小排序，敏感系数高 → 风险点。

### D. 临界点表

```
临界值 = 让 IRR = 行业基准的因子值
临界变化率 = (临界值 - 基准值) / 基准值
```

⚠️ 临界变化率越小，因子越敏感。

## 4. 盈亏平衡分析（BEP）

### 量盈亏平衡

```
量盈亏平衡产量 BEP_Q = 固定成本 / (单价 - 单位变动成本)
```

### 价盈亏平衡

```
价盈亏平衡价格 BEP_P = (固定成本 + 总变动成本) / 销量
```

### 安全裕度

```
安全裕度 = (实际销量 - BEP_Q) / 实际销量 × 100%
```

⚠️ 安全裕度 < 30% → 项目脆弱。

### 关键：成本要拆分固定 vs 变动

```
固定成本：折旧、摊销、管理人员工资、利息
变动成本：原材料、燃料动力、生产人员工资、销售提成
半变动：管理费用、销售费用（按 50% / 50% 拆分）
```

```markdown
### 6.6.1 敏感性分析

**分析方法**：单因素法

**分析因子**：销售收入、经营成本、建设投资、产能利用率、销售税金

**变化区间**：±10%、±20%

**分析结果**：

[敏感性分析表]
[敏感性曲线图]

**结论**：
- **最敏感因子**：销售收入。±10% 导致 IRR 变化 ±X 个百分点
- **次敏感因子**：经营成本、产能利用率
- **不敏感因子**：销售税金

[临界点表]

**风险提示**：销售收入下浮 15% 时 IRR 接近行业基准。需在销售环节做好风险防控（详见第 7 章 7.2 节）。

### 6.6.2 盈亏平衡分析

**量盈亏平衡产量**：BEP_Q = X 万吨/年
**价盈亏平衡价格**：BEP_P = X 元/吨
**安全裕度**：X%

**结论**：达产年安全裕度 X%，盈亏抗压能力 [充足 / 一般 / 较弱]。
```

## 6. 常见陷阱

### 陷阱 1：只做 1-2 个因子
❌ 错：只做销售收入和经营成本
✅ 对：至少 5 个因子

### 陷阱 2：基准 IRR 与 6.5 不一致
❌ 错：6.5 写 IRR = 12.5%，6.6 表的"基准"列写 11.8%
✅ 对：基准列必须 = 6.5 的 IRR

### 陷阱 3：浮动 ±5% 偷懒
❌ 错：所有因子只浮动 ±5%
✅ 对：至少 ±10%、±20% 两档

### 陷阱 4：盈亏平衡用错成本拆分
❌ 错：管理费用全算固定
✅ 对：管理费用按 50% / 50% 拆分（业内惯例）

### 陷阱 5：用平均量做安全裕度
❌ 错：用 15 年平均销量做安全裕度
✅ 对：用达产年销量

### 陷阱 6：敏感性结论与第 7 章脱节
❌ 错：6.6 说销售收入最敏感，7 章却没把市场风险列高风险
✅ 对：6.6 高敏因子 → 7 章高风险（呼应）

## 关键避免

- 不要只贴敏感性表，必须配曲线图和文字结论
- 不要让基准 IRR 与 6.5 节不一致
- 不要漏临界点分析（评审重点关注）
- 不要让"销售税金"占 5 个因子之一（敏感性低，浪费配额）—— 优先用原材料 / 工期等高敏因子
