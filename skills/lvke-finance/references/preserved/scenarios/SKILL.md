# 多场景分析 规范

场景分析（Scenario Analysis）与敏感性分析的区别：**敏感性是单因素改变，场景是多因素同向改变**。是大型项目财务可行性的标准动作。

## 1. 三场景标准设置

### 基准场景（Base Case）

参数设置：所有假设按"最可能"取值
- 销售收入：按合理需求预测中位数
- 经营成本：按当前价格水平
- 建设投资：按 5.4 总投资
- 工期：按 4.8 进度
- 政策：按现行不变

⚠️ 基准场景的 IRR / NPV = 第 6.5 节的"基准 IRR / NPV"。

### 乐观场景（Best Case / Upside）

参数设置：多个有利因素同向变化
- 销售收入 +10% ~ +15%
- 经营成本 -5% ~ -10%
- 建设投资节约 -5% ~ -10%
- 政策红利落实
- 工期按计划

### 悲观场景（Worst Case / Downside）

参数设置：多个不利因素同向变化
- 销售收入 -10% ~ -15%
- 经营成本 +5% ~ +10%
- 建设投资超支 +10% ~ +15%
- 政策不利变化
- 工期延长 6 个月 ~ 1 年

⚠️ **悲观场景的设置最重要**。评审最关心"最坏情况能不能扛"。

## 3. 场景概率加权 IRR（可选高级）

```
期望 IRR = 概率(乐观) × IRR(乐观) + 概率(基准) × IRR(基准) + 概率(悲观) × IRR(悲观)
```

常见概率：
- 乐观 20% / 基准 60% / 悲观 20%
- 乐观 25% / 基准 50% / 悲观 25%
- 乐观 30% / 基准 50% / 悲观 20%（偏乐观项目）

⚠️ 概率分配必须有依据。**不要为了"凑出可行结论"调概率**。

## 4. 场景参数设置 5 个原则

1. **多因子同向** —— 场景核心是"多个事情一起好或一起坏"，不是单因素
2. **逻辑合理** —— 销售收入跌不能与产能利用率涨同时出现
3. **保守为先** —— 悲观场景宁可设得更悲观一些
4. **行业差异化** —— 周期性行业悲观幅度更大（±20%~30%），稳定行业更小（±5%~10%）
5. **写明依据** —— 每个场景的参数变化幅度要有论证

## 5. 场景分析与敏感性的关系

| | 敏感性 | 场景 |
|---|---|---|
| 因子数 | 1 个 | 多个 |
| 变化方向 | 上下浮 | 多因子同向 |
| 目的 | 找敏感点 | 看综合表现 |
| 报告位置 | 6.6.1 | 6.6.2 / 6.6.3 |
| 与第 7 章 | 高敏因子 → 高风险 | 悲观场景对应风险情境 |

⚠️ 两者**互补不替代**，都要做。

## 6. 决策应用

### 投资决策

- 基准场景 IRR > 基准 + 悲观场景 IRR > 基准 → **强投资**
- 基准场景 IRR > 基准 + 悲观场景 IRR < 基准 → **谨慎投资**（要看悲观差距）
- 基准场景 IRR > 基准 + 悲观场景 IRR << 基准 → **高风险投资**（需配强对策）
- 基准场景 IRR < 基准 → **不应该投**

### 融资决策

- 悲观场景下能否覆盖本息 → DSCR（偿债保障比） ≥ 1.0
- 银行评审最关注悲观场景

### 风控决策

- 悲观场景的触发条件 → 风险预警阈值
- 悲观场景的应对措施 → 第 8 章保障措施

## 7. 常见陷阱

### 陷阱 1：场景参数随手拍
❌ 错：乐观 +10% / 悲观 -10% 不论行业
✅ 对：根据行业波动幅度合理设置

### 陷阱 2：悲观场景 IRR 还是正的
❌ 错：基准 12.5% / 悲观 11.8%（差距太小，没拉够）
✅ 对：悲观场景应拉到接近或低于行业基准

### 陷阱 3：乐观场景过分
❌ 错：销售收入 +30% + 经营成本 -20% + 投资节约 -20%
✅ 对：合理乐观（+10% ~ +15% 区间）

### 陷阱 4：与敏感性混淆
❌ 错：场景分析只改一个因子
✅ 对：多因子同向

### 陷阱 5：场景概率不合理
❌ 错：悲观概率 5%（过度乐观自我安慰）
✅ 对：悲观概率 20-30%

### 陷阱 6：场景结论与对策脱节
❌ 错：悲观场景 IRR 6.8% < 基准 8%，结论说"项目可行"
✅ 对：明确说"悲观下不可行，需配套 X / Y / Z 风控措施"

## 关键避免

- 不要让悲观场景 IRR 仍然漂亮（≥ 行业基准）
- 不要让 3 场景的"参数变化幅度"无依据
- 不要把场景分析和敏感性合并 —— 它们是两件事
- 不要让概率加权 IRR 替代"基准 IRR" 做主判断
