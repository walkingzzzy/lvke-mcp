# 税费假设 规范

可研报告税费假设错误是评审最常发现的问题之一。**税率拍头 / 漏税种 / 优惠超期 / 增值税口径错**都是硬伤。

## 1. 主要税种 速查

### 增值税

- 一般纳税人税率：
  - 13%（多数工业销售货物）
  - 9%（农产品、不动产销售、交通运输、建筑等）
  - 6%（现代服务业、金融、生活服务等）
  - 0%（出口货物）
- 小规模纳税人征收率：3%（疫情期减按 1% 至 2027 年底）

⚠️ 增值税 ≠ 经营成本。**增值税计算时收入和成本都要含税或都不含税，统一口径**。建议全表用 **不含税** 价。

### 企业所得税

- 法定税率：25%
- 高新技术企业：15%
- 西部大开发鼓励产业（湖北部分地区适用）：15%
- 海南自贸港鼓励产业：15%
- 小型微利企业：分段优惠（2024 年起按 5% 实际税率）
- 资源综合利用：减按 90% 计入收入

### 城建税

```
城建税 = (增值税 + 消费税) × 税率
税率：市区 7%、县城/镇 5%、其他 1%
```

### 教育费附加

```
教育费附加 = (增值税 + 消费税) × 3%
地方教育费附加 = (增值税 + 消费税) × 2%
合计 = 5%
```

### 印花税

- 购销合同：万分之三
- 借款合同：万分之零点五
- 财产保险合同：千分之一
- 营业账簿：实收资本和资本公积合计金额的万分之二点五

### 土地相关税

- 土地使用税：定额征收（按地段），通常 0.6-30 元/m²/年
- 耕地占用税：占用耕地一次性征收，地区差异 5-50 元/m²

### 房产税

```
房产税 = 房产原值 × (1-30%) × 1.2%（自用）
或 = 房产租金 × 12%（出租）
```

### 资源税 / 消费税（行业相关）

⚠️ 行业特殊税种要查 SAT 当前公告。

## 2. 销售税金及附加 标准计算

```
销售税金及附加 = 增值税 × (城建税率 + 教育附加率)
                  + 消费税（若适用）
                  + 资源税（若适用）

对于 大多数工业项目（市区）：
销售税金及附加 ≈ 增值税 × 12%
```

## 3. 财务模型 5 个口径标准

### 口径 1：含税 vs 不含税

✅ 推荐：**全表用不含税价**
- 收入：销售收入（不含税）
- 成本：原材料、燃料等（不含税）
- 增值税单独行 = 销项 - 进项

⚠️ 全表统一是关键。**不能某行含税某行不含税**。

### 口径 2：所得税前 vs 所得税后

- 项目 IRR / NPV：**税后**
- 资本金 IRR / NPV：**税后**
- 行业基准收益率：**对应税后口径**

⚠️ 不要拿税前 IRR 对税后基准。

### 口径 3：所得税抵扣

可抵扣项：
- 折旧 / 摊销
- 利息（财务费用）
- 大部分经营成本
- 销售税金及附加

不可抵扣：
- 罚款 / 滞纳金
- 超标的业务招待费
- 行政性罚款
- 个别捐赠

### 口径 4：建设期与运营期

- 建设期：原则无所得税（无收入）
- 试运行期：少量收入要交税
- 达产期：标准计税

### 口径 5：增值税留抵 / 退税

- 增值税进项税额可累积留抵
- 部分行业可申请期末留抵退税
- 退税在现金流中算"流入"

## 4. 税收优惠 标准做法

### 优惠类型

| 类型 | 适用 | 期限 | 备注 |
|---|---|---|---|
| 高新技术企业 | 全行业可申请 | 3 年（每 3 年复审） | 所得税 15% |
| 西部大开发 | 西部 12 省（含湖北部分） | 至 2030 年底 | 所得税 15% |
| 资源综合利用 | 利用废弃物 | 长期 | 收入减 10% |
| 增值税即征即退 | 软件 / 资源综合利用 | 长期 | 部分行业 |
| 三免三减半 | 鼓励行业 | 6 年 | 视行业 |
| 加计扣除 | 研发费用 | 长期 | 100% / 200% 加计 |

### 优惠假设规范

1. **明确依据**：引用具体文件（如"湖北省高新区高新技术企业认定办法 2024 年版"）
2. **期限准确**：高新企业 3 年复审，模型按期还原 25%
3. **不假设过度**：不能假设永远适用所有优惠
4. **保守做法**：基准场景按 25%，敏感性场景看 15% 的额外收益

## 6. 报告写法

```markdown
**税费假设**：

| 税种 | 税率 | 计税依据 | 备注 |
|---|---|---|---|
| 增值税 | 13% | 销售收入（不含税） | 一般纳税人 |
| 城建税 | 7% | 实缴增值税 | 市区税率 |
| 教育费附加 | 3% | 实缴增值税 | - |
| 地方教育费附加 | 2% | 实缴增值税 | - |
| 印花税 | 万分之三 | 购销合同 | - |
| 企业所得税 | 25%（拟申请高新企业 15%） | 利润总额 | 谨慎按 25% 计入基准场景 |
| 城镇土地使用税 | 5 元/m²/年 | 占地面积 | 当地标准 |

**优惠政策预期**（不计入基准场景，仅敏感性参考）：
- 高新技术企业认定（运营第 2 年起，按 15% 计税，每 3 年复审）
- 设备投资抵扣（如适用）
```

## 7. 常见陷阱

### 陷阱 1：增值税含税不含税混用
❌ 错：收入按含税价，成本按不含税价
✅ 对：全表统一不含税

### 陷阱 2：销售税金及附加只算一部分
❌ 错：只算城建税 7%，漏教育附加 5%
✅ 对：城建 7% + 教附 3% + 地附 2% = 12%

### 陷阱 3：所得税优惠永久化
❌ 错：高新企业 15% 用到运营第 15 年
✅ 对：每 3 年复审，谨慎按 25% / 15% 切换

### 陷阱 4：忽略印花税 / 土地使用税
❌ 错：只算增值税、所得税、城建税
✅ 对：印花税虽小但要列；土地使用税常被忽略

### 陷阱 5：建设期算所得税
❌ 错：建设期 3 年算所得税
✅ 对：建设期无所得税

### 陷阱 6：折旧后还算成本
❌ 错：经营成本 + 折旧 + 摊销 三项分开扣
✅ 对：经营成本 + 销售税金及附加 → 利润总额 → 所得税 → 净利润 + 折旧（加回）

### 陷阱 7：用上年税率
❌ 错：用 2024 年 1 月废止的优惠
✅ 对：查最新 SAT 公告

## 关键避免

- 不要把"增值税"算入经营成本
- 不要把销售税金及附加合并计为 17%（错把销售税金及附加和增值税混算）
- 不要假设永久高新企业优惠
- 不要忽略地方教育附加 2%
- 不要假设湖北以外的西部优惠政策
