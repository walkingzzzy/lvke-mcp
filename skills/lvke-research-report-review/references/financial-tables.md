# Financial Tables Domain

Use `FINTABLE.SUBSTANTIVE.REVIEW` after deterministic table/model reconciliation.

Check within-table sums, cross-table links, profit/cash-flow/balance-sheet relationships, investment/funding balance, debt roll-forward, tax bases, depreciation, working capital, opening/closing balances, monthly-to-annual reconciliation, units, periods, currencies, and report-number consistency.

Identify each metric by canonical meaning, period, entity, unit, and source run. A visually matching number with a different period or basis is a mismatch. State tolerances and never close a mismatch without a new child review.
