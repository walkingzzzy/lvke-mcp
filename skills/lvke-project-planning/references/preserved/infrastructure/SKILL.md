# 基础设施 可研要点

基础设施投资规模大、周期长、公益性强。**评审重点是社会效益 / 民生效益 + 财政可承受性**，财务收益通常不是首位。

## 1. 道路工程

### 单位投资参考

| 等级 | 单位投资 |
|---|---|
| 高速公路（4-6 车道） | 1.5-3 亿元/km |
| 一级公路 | 5000-10000 万/km |
| 二级公路 | 2000-5000 万/km |
| 城市快速路 | 8000-15000 万/km |
| 城市主干路 | 5000-10000 万/km |
| 城市次干路 | 3000-6000 万/km |

⚠️ 山区桥梁 / 隧道 / 软基 / 拆迁 严重影响投资强度。

### 建设周期

- 高速公路：3-5 年
- 一般公路：1.5-2.5 年
- 城市道路：1-2 年

### 收入模式

- 收费公路：通行费（按车次 + 路段长度）
- 非收费公路：政府财政（无项目收入）
- 一级 / 二级公路：基本不收费

### 审批

- 高速公路 → 省发改委及以上
- 一级公路 → 省发改委
- 二级公路 → 市发改委
- 城市道路 → 市发改委

## 2. 铁路工程

### 单位投资参考

| 类型 | 单位投资 |
|---|---|
| 高速铁路 | 1.2-2 亿元/km |
| 普速铁路 | 6000-10000 万/km |
| 重载铁路 | 8000-15000 万/km |
| 货运专线 | 5000-8000 万/km |
| 城际铁路 | 1.2-1.8 亿元/km |
| 市域铁路 | 5000-12000 万/km |

### 建设周期

- 高速铁路：5-7 年
- 普速铁路：3-5 年

### 审批

- 高速铁路 / 普速铁路 → 国家发改委
- 城际铁路 / 市域 → 国家发改委（按规划） / 省发改委

## 3. 桥梁 / 隧道

### 单位投资

| 类型 | 单位投资 |
|---|---|
| 大型公路桥（万吨级） | 5-20 亿元/座（含引桥） |
| 高架桥 | 1-3 亿元/km |
| 跨海大桥 | 5-20 亿元/km |
| 公路隧道 | 0.5-2 亿元/km（视长度 / 地质） |
| 铁路隧道 | 1-3 亿元/km |

⚠️ 桥隧投资强度差异极大，**必须做地勘后再估算**。

## 4. 水利工程

### 单位投资

| 类型 | 单位投资 |
|---|---|
| 大型水库 | 总投资数十至数百亿，无统一指标 |
| 中型水库 | 总投资数亿至数十亿 |
| 灌区工程 | 5000-15000 元/亩 |
| 防洪堤防 | 1000-5000 万/km |
| 调水工程 | 数千万至上亿/km |

### 审批

- 大型水库 → 国务院或国家发改委
- 中型水库 → 国家发改委或省发改委
- 中小型水利 → 省 / 市发改委

### 重要点

- 必做水土保持审批
- 必做生态流量论证（长江流域要求严）
- 必做防洪影响评价
- 多年调节水库要做移民评估

## 5. 市政基础设施

### 给排水

| 类型 | 单位投资 |
|---|---|
| 水厂 | 1000-3000 元/m³/日（视规模与水源） |
| 污水处理厂 | 2000-5000 元/m³/日 |
| 给水管网 | 800-2000 元/m（视管径） |
| 排水管网 | 1000-3000 元/m（视管径与方式） |

### 燃气 / 热力

| 类型 | 单位投资 |
|---|---|
| 燃气管网（高压输配） | 数千万至上亿/km |
| 城市燃气分配管 | 200-800 元/m |
| 集中供热 | 1500-3500 元/kW |

### 综合管廊

| 类型 | 单位投资 |
|---|---|
| 干线综合管廊（大型） | 0.5-1.2 亿元/km |
| 支线管廊 | 2000-5000 万/km |
| 缆线管廊 | 500-2000 万/km |

⚠️ 综合管廊近年是市政热点，但**财务收益差**，主要靠管线入廊费 + 政府补贴。

## 6. 物流园区 / 物流基础设施

| 类型 | 单位投资 |
|---|---|
| 大型物流园 | 800-2000 元/m²（仓储） |
| 冷链仓储 | 3000-6000 元/m² |
| 公路港 | 1500-3500 元/m² |
| 多式联运枢纽 | 数亿至数十亿 |

## 7. 财务特性

### 政府投资项目（占大多数）

- 不追求 IRR 高
- 项目 IRR 一般 4-8%
- 评价指标更重视：单位投资效益（如增加 GDP/亿元、就业岗位/亿元）

### 经营性项目

| 项目类型 | 项目 IRR 阈值 |
|---|---|
| 收费公路 | 6-9% |
| 物流园 | 8-12% |
| 燃气供应 | 6-9% |
| 污水处理 | 5-8% |

### 政府补贴 / 财政承受能力

PPP 或政府投资项目要做：
- 财政承受能力评估
- 中长期债务 / GDP 比例
- 政府支付义务 / 一般公共预算占比（< 10%）

## 8. 监管约束

| 类型 | 关键审批 |
|---|---|
| 道路 | 选址 / 用地 / 林地 / 水保 / 环评 / 防洪 / 文物 |
| 铁路 | 国家发改委审批 / 选址 / 环评 / 用地 / 安评 |
| 水利 | 水保 / 防洪评价 / 移民评估 / 环评 |
| 市政 | 规划 / 用地 / 环评 / 安评 |
| 综合管廊 | 与各市政管线协调 |

## 9. 风险特性

| 风险 | 基础设施 |
|---|---|
| 政策风险 | 高（投资周期跨多届政府） |
| 市场风险 | 低（公共属性强） |
| 技术风险 | 低（成熟工艺） |
| 财务风险 | 中（杠杆高 + 长周期） |
| 实施风险 | 高（征地 / 拆迁 / 用地审批） |
| 环境风险 | 高（生态 / 文物） |

## 10. 报告中的写法 要点

- 第 2 章重点写**社会效益**（缓解拥堵 / 促进区域协同 / 防洪减灾 / 改善民生）
- 第 3 章写需求 / 流量预测（用模型支撑）
- 第 4 章方案比选要厚（线路 / 桥位 / 工艺）
- 第 5 章估算要细（拆迁费 / 林地补偿 / 文物 / 占补平衡都要列）
- 第 6 章财务分析对政府投资项目可简化（重在财政承受能力）
- 第 7 章环境与社会风险要重点写

## 11. 湖北特点

- **沿江沿河项目** —— 长江保护 / 防洪 / 生态约束严
- **国家中部地区高质量发展示范** —— 重大基础设施投资集中
- **武汉都市圈交通一体化** —— 城际铁路 / 市域铁路 / 城际公路网
- **长江中游航运中心** —— 武汉 / 黄石 / 宜昌港口枢纽
- **平原 / 山区差异大** —— 江汉平原投资强度低，鄂西山区投资强度高

## 关键避免

- 不要在政府投资项目硬追求高 IRR
- 不要在基础设施估算里漏拆迁 / 文物补偿
- 不要忽略防洪影响评价 / 水保审批
- 不要在线路 / 桥位比选时只写"经比较推荐 A 方案"
- 不要忽略征地拆迁周期对工期的影响
