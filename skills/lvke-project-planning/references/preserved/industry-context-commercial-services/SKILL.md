# 商业服务

适用于零售、商业综合体、生活服务和现代服务业。酒店资产收购使用专属收购 Skill；房地产开发销售不得套用本 Skill 的持续经营模型。

## 最低输入与对象

固化 ProjectContext、商圈/客户分层 MarketSizingCase、经营面积 BuildScaleCase、业态 RevenueDriverSet、租金/人工/营销/能耗 CostDriverSet 和岗位 LaborPlan。租赁结构必须明确出租率、免租期、租金增长、物业费和商户更替；服务收费明确量、价、爬坡和退款口径。

## 财务与风险

分别建模自营收入、租赁收入和服务收入，不把 GMV 当营业收入。场景至少覆盖客流/订单、客单价、出租率、人工和获客成本。审查竞争、消费变化、租约集中、现金回收、消防、数据与消费者权益风险。

## 标准边界

通过政策与标准工具锁定现行消防、无障碍、建筑、价格、消费者保护和数据要求。禁止把行业均值当项目证据，禁止在无明确 transaction structure 时加载契税、土地增值税或资产收购规则。
