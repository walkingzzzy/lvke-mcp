# 现代农业 / 农产品加工 可研要点

湖北是粮食主产省和农业大省。**农业类项目常涉及高标准农田、设施农业、农产品加工产业园、智慧农业**。本 skill 覆盖关键要点。

## 1. 高标准农田建设

### 单位投资参考

| 类型 | 单位投资 |
|---|---|
| 高标准农田（基础） | 1500-3000 元/亩 |
| 高标准农田（含智能化） | 3000-5000 元/亩 |
| 灌区现代化改造 | 5000-15000 元/亩 |
| 旱改水 | 3000-8000 元/亩 |

### 主要内容

- 土地平整 / 改良
- 灌溉与排水（水源 / 渠系 / 管道 / 计量）
- 田间道路（生产路 / 田间路）
- 农田防护与生态环境保护
- 农田输配电
- 科技服务支撑（监测设备 / 数据系统）

### 关键约束

- 必须在 **永久基本农田** 内（一般原则）
- 不能占用生态红线
- 与水利规划协调
- 与"国家级 / 省级高标准农田建设规划"对应

### 资金来源

- 中央财政 + 省级配套 + 县级配套
- 土地出让收入计提
- 社会资本（PPP / 农业银行专项贷）

## 2. 设施农业 / 现代农业园区

### 单位投资参考

| 设施类型 | 单位投资 |
|---|---|
| 连栋温室（大型） | 800-2500 元/m² |
| 单栋温室 / 大棚 | 100-500 元/m² |
| 智能温室（荷兰式） | 2500-5000 元/m² |
| 工厂化育苗 | 500-1500 元/m² |
| 蛋鸡 / 猪舍（设施化） | 2000-5000 元/m² |
| 水产养殖（循环水） | 3000-8000 元/m² |
| 仓储冷链（一般） | 1500-3500 元/m² |
| 冷链中心（生鲜） | 3000-6000 元/m² |

### 设施农业 财务特点

- 一次性投入大 → 折旧大头
- 运营成本可控（特别是智能温室）
- 产量稳定 → 现金流可预测
- 价格弹性大（季节性 + 品种）

## 3. 农产品加工

### 单位投资参考

| 子领域 | 投资强度 |
|---|---|
| 粮食加工（米面油） | 1500-4000 元/吨产能 |
| 食品加工（深加工） | 3000-10000 元/吨产能 |
| 茶叶加工 | 5000-15000 元/吨产能 |
| 油料加工 | 2000-5000 元/吨产能 |
| 肉食加工 | 3000-10000 元/吨产能 |
| 乳品加工 | 5000-15000 元/吨产能 |
| 中药材加工 | 5000-25000 元/吨产能 |

### 关键能力

- 原料采购体系（农户 / 合作社 / 自有基地）
- 加工工艺 / 标准化
- 冷链 / 仓储
- 销售渠道（线上 / 线下 / B2B / B2C）
- 品牌建设

### 监管约束

- **食品生产许可证**（SC 证）
- **HACCP / ISO 22000**
- **绿色食品 / 有机认证**（增加溢价）
- **地理标志保护产品**（如恩施富硒、利川莼菜、宜昌柑橘）

## 4. 智慧农业 / 数字农业

### 典型项目

- 农业物联网（传感器 / 网关 / 平台）
- 智慧灌溉
- 无人机植保
- 农业大数据平台
- 智慧养殖（自动饲喂 / 环控）
- 农产品溯源
- 农村电商 / 直播基地

### 投资特点

- 软件 / 平台占比大（不像传统农业重资产）
- 政府补贴 / 试点项目较多
- 与"5G+ 智慧农业"试点项目结合

### 财务挑战

- 收入模式不清晰（农户付费意愿低）
- 财政补贴依赖度高
- 运营 / 维护成本不易控制

## 5. 农村一二三产融合

### 典型模式

- 田园综合体
- 现代农业产业园
- 农业农村部 "一村一品" 示范
- "互联网 + 农业"
- "乡村旅游 + 农业"

### 政策支持

- 财政部 + 农业农村部 现代农业产业园
- 省级农业产业化龙头企业
- 农业产业强镇

## 6. 财务特性

### 收入

- **季节性强** —— 收入集中
- 价格波动大（生猪 / 水果尤甚）
- 政府补贴 / 农业保险并入收入
- 一二三产融合可平滑

### 成本

- 原料成本主导（季节波动）
- 人工 + 季节工
- 仓储 / 物流 / 损耗

### 财务指标参考

| 行业 | 项目 IRR 阈值 |
|---|---|
| 高标准农田 | 4-7%（政府投资） |
| 现代农业园区 | 6-10% |
| 一般农产品加工 | 8-12% |
| 高端 / 品牌加工 | 12-20% |
| 智慧农业（含补贴） | 6-10% |
| 田园综合体 | 6-10%（需财政补贴支撑） |

## 7. 风险特性

| 风险 | 农业项目 |
|---|---|
| 政策风险 | 中（农业政策稳定） |
| 市场风险 | 高（价格波动） |
| 技术风险 | 低-中 |
| 财务风险 | 中（季节性现金流） |
| 实施风险 | 低-中 |
| 环境风险 | 高（自然灾害 / 病虫害） |
| 食品安全风险 | 极高（一次事件影响品牌） |

## 8. 报告中的写法 要点

- 第 2 章必须分析国家粮食安全 / 农业现代化 / 乡村振兴政策
- 第 2 章要写本地农业基础（耕地面积、粮食产量、特色产品）
- 第 3 章要分析农产品市场（区域消费 / 出口 / 价格）
- 第 4 章重点：原料供应保障（合作社 / 订单农业 / 自有基地）
- 第 5 章：农业项目土地成本通常较低，但要写清地租 / 流转费
- 第 6 章：保守估价 + 多场景（丰年 / 平年 / 灾年）
- 第 7 章必含 **自然灾害风险**、**食品安全风险**、**价格波动风险**

## 9. 湖北农业 特定要点

### 重点品类

- **粮食**：水稻（江汉平原 / 鄂北岗地）、小麦（鄂北）、玉米
- **油料**：油菜（全国第一）
- **水产**：鄂州武昌鱼、洪湖大闸蟹、监利小龙虾
- **茶叶**：恩施玉露、英山云雾、利川红
- **特色**：恩施富硒农产品、潜江小龙虾、罗田板栗、随州香菇

### 重大政策 / 项目

- 长江流域重点水域禁捕（《长江保护法》）
- 江汉平原现代农业示范区
- 鄂西生态文化旅游圈 + 农业
- 武汉都市圈 "菜篮子" 工程
- 恩施 / 鄂西 "硒"产业

### 关键约束

- 永久基本农田保护红线严
- 长江保护法对水产养殖管控
- 化肥农药使用减量

- `report-drafting-chapter-2-background`：政策依据厚

## 关键避免

- 不要在永久基本农田上建非农业设施
- 不要假设农业项目"无风险"
- 不要把农产品加工项目当一般工业处理（季节性 / 自然灾害风险大）
- 不要忽略 SC 认证 / HACCP 体系建设投入
- 不要把"政府补贴 / 一次性奖励" 计入正常运营收入做 IRR
- 不要在长江流域禁捕区做水产养殖
