# 第 1 章 · 总论 起草

第 1 章是**全报告的执行摘要**。投委会成员往往只读这一章 + 第 9 章。**这章写不好，整本报告白写**。

## 必含 6 节

### 1.1 项目概况

要素：
- 项目名称（全称 + 简称）
- 建设性质（新建 / 改扩建 / 迁建 / 并购）
- 建设单位（全称 + 实控人）
- 建设地点（行政区 + 具体地块 / 园区）
- 建设规模与产品方案（一两句话）
- 总投资 / 建设期 / 主要建设内容
- 主要技术经济指标表（精简版，详见 1.5）

### 1.2 编制依据

要素：
- 委托方与编制方（合同关系）
- 法律法规依据（**3-5 条最相关**，不要堆砌 20 条）
- 政策依据（产业政策 / 地方政策）
- 行业标准依据（GB / DB）
- 数据资料依据（甲方提供清单 + 公开来源）

注意：依据应**真实可查**（见 `doc-review-citation-verification`）。

### 1.3 编制范围

明确"本报告不包括"什么 —— 例如：
- 不包括详细方案设计（属于初步设计阶段）
- 不包括施工组织方案
- 不包括 ESIA / 详细环评（另行委托）

### 1.4 项目建设单位概况

要素：
- 单位性质（国企 / 民企 / 合资 / 上市）
- 注册资本 / 实收资本
- 主营业务
- 近三年财务概况（资产、收入、利润、资产负债率）
- 信用 / 资质（行业准入资质、ISO 等）
- 历史承担类似项目情况（可加深可信度）

### 1.5 主要技术经济指标

**最重要**的一节。表格化展示：

| 指标 | 数值 | 单位 |
|---|---|---|
| 总投资 | XXX | 万元 |
| ├─ 建设投资 | XXX | 万元 |
| ├─ 流动资金 | XXX | 万元 |
| 资本金 / 融资比 | XX% / XX% | - |
| 建设期 | XX | 月 |
| 运营期 | XX | 年 |
| 产品方案 | XX / XX | 万吨/年 |
| 占地面积 | XX | 亩 / 平方米 |
| 总建筑面积 | XX | 平方米 |
| 总人员 | XX | 人 |
| 财务内部收益率（税后，全投资） | XX.X% | - |
| 财务内部收益率（税后，资本金） | XX.X% | - |
| 财务净现值（@基准贴现率） | XXX | 万元 |
| 投资回收期 | XX.X | 年 |

⚠️ 数字必须与第 5 / 6 章一致（见 `doc-review-numerics-cross-check`）。

### 1.6 主要结论

**3 段法**：

```
段 1（一句话定性）：
本项目符合 XX 产业政策导向；总投资 XXX 万元；建设期 XX 个月、运营期 XX 年；
项目财务可行性良好（IRR XX.X% > 行业基准）。

段 2（关键支撑）：
- 政策合规性：通过 X / X / X 审批前置评估
- 市场需求：测算需求 XXX、缺口 XXX、本项目占缺口比例 XX%
- 经济性：IRR / NPV / 回收期均超过基准
- 风险水平：主要风险为 X / Y / Z，已制定应对措施

段 3（明确建议）：
建议本项目立项 / 建议条件性立项（需补 X / Y） / 建议暂缓。
```

**绝对禁忌**：

- 「项目意义重大、建议批准」这种空洞结论
- 摘要 IRR 与正文 IRR 不一致
- 风险章节列出的关键风险摘要里没提

## 常见缺陷（按出现频率）

1. **数字不一致**（最常见）—— 1 章数字 vs 5/6 章数字差异
2. **结论空洞** —— "意义重大、强烈建议"无量化
3. **依据陈旧** —— 引用 5+ 年前的政策没更新
4. **编制范围模糊** —— 不写"不包括什么"，评审专家追问
5. **建设单位概况太短** —— 没提资质 / 历史项目 → 评审专家担心承担能力
6. **缺关键指标** —— 漏 IRR / 回收期 / NPV 之一
