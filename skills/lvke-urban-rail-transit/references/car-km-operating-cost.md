# 车公里运营成本

定运营成本。承载工具：`planning_calculate_cost_drivers`。

## 车公里是基本口径

```
年运营车公里 = 配属列车数 × 编组辆数 × 日走行公里 × 年运营天数
运营成本     = 年运营车公里 × 单位车公里成本
```

配属列车数由行车间隔、旅行速度与线路长度推导，不是独立假设：

```
最少上线列车数 ≈ 2 × 线路长度 ÷ (旅行速度 × 行车间隔)
配属列车数     = 上线列车数 × (1 + 检修备用率)
```

## 成本构成

按 `cost_items` 分项填写，至少覆盖：人工、动力（牵引与动力照明）、维修（工务、车辆、
供电、信号）、管理费。任一分项缺失时 `finance_run_model` 报
`cost_items_or_operating_cost_by_year`。

## 门禁

- 不用"占收入比例"倒算成本。轨道项目票务收入本身依赖客流与清分票价，
  用比例倒算会让成本随收入同步漂移，敏感性分析全部失效。
- 单位车公里成本必须有 locator：可比线路运营数据或工可运营成本专题。

## 反模式

- 用"运营成本占收入 60%"直接给成本 → 与车公里口径脱节，敏感性失真
- 用单位面积成本或人均成本推轨道运营成本 → 错口径
