# 投资估算与单位里程强度

定建设投资与单位里程投资强度。承载工具：`finance_build_basis_of_estimate`、
`finance_prepare_spec`。

## 单位里程强度参考区间

参考区间为 **3.0~12.0 亿元/公里**（见 `scale_guard.URBAN_RAIL_INVEST_INTENSITY`）。
下限对应地面/高架简易制式，上限对应全地下高造价段。

区间只用于**尺度对账与提示，绝不用于改值**：
- 实际投资与按区间推算值相差超过 3 倍 → `project_scale_inconsistent`，阻断建 run。
- 落在区间外但未超 3 倍 → `invest_intensity_outside_reference` 提示，需证据说明。

## 地下段与高架段不得摊平

全地下段单位造价可达高架段的 2~3 倍。按敷设方式分段估算：

```
建设投资 = Σ(各段长度 × 该敷设方式单位造价) + 车辆购置 + 车辆段 + 系统设备
```

用全线单一均价摊平，会在地下比例高的线路上系统性低估。

## 门禁

- 总投资必须以工可批复或可比项目证据显式提供，不得沿用通用行业种子。
  50 公里线路套用通用单体项目投资种子，即使算术自洽也必须阻断。
- `total_investment_wan` 在 InputRevision 中已含建设期利息，在假设包中不含；
  两者是合法口径差，不得直接互相对账。

## 反模式

- 用行业种子投资额直接跑 50 公里线路 → 尺度不一致
- 用参考区间自动改写证据给定的投资额 → 区间只报不改
